# Stock Explorer - 기획서

## 프로젝트 개요

KOSPI/KOSDAQ 상장기업의 DART 전자공시 데이터를 수집하고, 재무·사업·공시·밸류에이션 정보를 차트와 테이블로 시각화하는 **로컬 대시보드**이다.

CompanyGuide / FnGuide 수준의 기업 분석 화면을 개인 환경에서 무료로 구현하는 것이 목표이며, DART OpenAPI와 KRX 데이터를 활용한다.

---

## 해결하려는 문제

- 유료 서비스(FnGuide, CompanyGuide) 없이도 상장기업의 재무·공시·밸류에이션 데이터를 한 화면에서 분석하고 싶다.
- DART API를 매번 호출하면 느리고 일일 한도(10,000건)가 있으므로, 로컬 DB에 캐싱하여 빠르게 반복 조회할 수 있어야 한다.
- 컨퍼런스콜/IR 내용 등 정형화되지 않은 정보를 기업별로 메모 형태로 관리하고 싶다.

---

## 핵심 기능

### 1. 기업 검색 및 선택
- 기업명 또는 6자리 종목코드로 검색
- 자동완성 드롭다운에서 선택 → 대시보드 전환

### 2. 요약 (Summary)
- 매출액·영업이익·순이익 연도별 요약 테이블 (YoY 증감률 포함)
- 실적 추이 차트 (매출액 + 영업이익 Bar, 영업이익률 Line)
- 시가총액 미니 차트
- 최근 공시 5건

### 3. 재무정보 (Financial Statements)
- **3대 재무제표**: 손익계산서, 재무상태표, 현금흐름표
- **기간 토글**: 분기별 / 연도별 / 4분기 누적
- **범위**: 5년 / 10년
- **재무제표 유형**: 연결(CFS) / 별도(OFS)
- **뷰 전환**: 테이블 ↔ 차트
- YoY 성장률 표시 (▲빨강 / ▼파랑)

### 4. 사업정보 (Business Segments)
- 사업부문별 / 사업지역별 매출 데이터
- 파이차트 (최신 연도 비중) + 스택 바차트 (연도별 추이)
- 데이터 테이블 (CRUD — 사용자 직접 입력)
- *참고: DART API가 구조화된 세그먼트 데이터를 제공하지 않아 수동 입력 방식*

### 5. 공시 / IR 메모
- **공시 목록**: DART 공시 검색 (종류별 필터: 정기공시, 주요사항, 발행, 지분, 기타)
  - 페이지네이션, DART 원문 링크
- **IR 메모**: 컨퍼런스콜·IR 주요 내용을 사용자가 직접 CRUD
  - 날짜, 제목, 본문 (자유 텍스트)

### 6. 지표 차트 (Key Metrics)
- 매출액 & 영업이익 & 영업이익률 (ComposedChart)
- 이익률 추이 (매출총이익률, 영업이익률, 순이익률)
- 성장률 YoY (매출액, 영업이익, 순이익)
- 분기/연도 토글, 5/10년 범위

### 7. 시가총액 (Market Cap)
- 시가총액 AreaChart + 주가 AreaChart
- 기간 범위: 1년 / 3년 / 5년 / 10년

### 8. 밸류에이션 (Valuation)
- **PBR 밴드**: 과거 PBR 분위수(10/25/50/75/90%)로 산출한 가격 밴드 vs 실제 주가
- **PER 차트**: PER 추이 + 주가 오버레이
- **EPS 차트**: 주당순이익 Bar + 주가 오버레이

## 데이터 소스

| 소스 | 제공 데이터 | 라이브러리 |
|------|------------|-----------|
| DART OpenAPI | 재무제표, 공시 목록, 기업 고유번호 | OpenDartReader |
| KRX (한국거래소) | OHLCV, 시가총액, PER/PBR/EPS/BPS | pykrx |

---

## UI 요구사항

- **Light mode** (다크모드 미사용)
- 깔끔한 카드 기반 레이아웃, 전문적인 분위기
- 상단: 기업 검색 → 탭 네비게이션
- 탭: 요약 | 재무정보 | 사업정보 | 공시/IR | 지표차트 | 시가총액 | 밸류에이션
- 반응형 그리드 (차트 카드 2~3열)
- 숫자 포맷: 한국식 (억, 조 단위)

---

## 배포 및 운영

- **로컬 전용** — 개인 PC에서 백엔드 + 프론트엔드 동시 실행
- DART API 키: `.env` 파일로 관리
- SQLite로 데이터 캐싱 → 네트워크 없이도 캐시된 데이터 조회 가능
