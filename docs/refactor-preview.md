# 로컬 리팩토링 미리보기

- 주소: `http://127.0.0.1:18005/feed` (Mac mini에서만 접근)
- 읽기 전용 시험이다. 리허설 사본의 마지막 문서 수집 시각은 DB 기록 기준 `2026-11-14 09:37:32`이며 시간대 표기는 없다. MacBook의 최신 자료가 아니다.
- PostgreSQL 시험 경로: 피드·타임라인·채널·문서 상세·논점, 신호 목록/요약/모멘텀, 내러티브 목록/상세, 컨콜 분기/상세. 검색은 텍스트 검색이다.
- 기존 읽기 전용 viewer 경로: 홈, 관련 문서, 컨콜 팔로우/최근 목록, 산업 지도/상세, 첨부 파일. 이 경로는 새 백엔드 성능이 아니다.
- 두 경로는 같은 시점에 고정돼 있지 않아 자료나 첨부가 서로 다를 수 있다. 검색 색인과 조회 사본은 수집 중에 자동 갱신되지 않는다.
- 나머지 API와 모든 데이터 변경 요청은 차단된다. 화면 전체 호환, 운영 전환, 회원 기능, 최신 데이터 동기화가 아니다.
- 각 API 응답의 `X-Preview-Backend` 헤더는 `postgres` 또는 `existing-viewer`로 출처를 나타낸다. `/__preview-info`에서도 범위를 확인할 수 있다.
- 임시 자원은 자동 재시작하지 않는다. 시험 종료 시 이 저장소에서 `sh scripts/stop-refactor-preview.sh`를 실행한다. 소유 레이블이 확인된 전용 DB 볼륨만 삭제하며 운영 viewer와 MacBook은 건드리지 않는다.
- 이후 새 시험 사본을 만들 때 loader에 `REFACTOR_INCLUDE_CENTROIDS=1`을 명시하면 같은 SQLite 읽기 트랜잭션에서 관련 문서 벡터도 확보할 수 있다. 별도 실험에서 실제 사본 문서 3건의 관련 문서 결과가 기존 조회와 일치했다. 현재 18005 사본에는 적용되지 않았고 더 넓은 호환성은 미검증이다.
