# 화면 기획서: 카탈리스트 캘린더

> 경로: `/research/catalysts`
> 상태: 기획 완료, 구현 대기

---

## 1. 목적

투자 종목의 **향후 주가 촉매 이벤트를 타임라인으로 관리**한다.
"이 종목, 다음 이벤트가 언제지?"를 빠르게 파악.

---

## 3. 이벤트 타입

| 타입 | 아이콘 | 색상 | 예시 |
|------|-------|------|------|
| 실적발표 | 📊 | blue | 분기 잠정실적, 사업보고서 |
| 공시예정 | 📋 | gray | 반기/분기 보고서 제출 |
| 계약/수주 | 📝 | emerald | 수주 결과 발표, 계약 완료일 |
| 설비/투자 | 🏭 | amber | 신규 라인 가동, CAPEX 집행 |
| 규제/정책 | ⚖️ | rose | 인허가, 정부 정책 발표 |
| 기타 | 📌 | gray | 락업 해제, 주총, 배당 기준일 |

---

## 4. 이벤트 추가 폼

| 필드 | 타입 | 필수 | 기본값 |
|------|------|------|-------|
| 종목 | 자동완성 (워치리스트 우선) | ✓ | - |
| 이벤트 타입 | 드롭다운 | ✓ | 실적발표 |
| 날짜 | 날짜 선택기 | ✓ | 오늘 |
| 제목 | 텍스트 | ✓ | - |
| 설명 | 텍스트 | ✗ | - |

---

## 5. 데이터 모델

### DB 테이블: `catalysts`

| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | INTEGER PK | |
| stock_code | TEXT | 종목코드 (NULL 가능 = 시장 전체 이벤트) |
| corp_code | TEXT | |
| event_type | TEXT | earnings/filing/contract/capex/regulation/other |
| event_date | TEXT | YYYY-MM-DD |
| title | TEXT | 이벤트 제목 |
| description | TEXT | 상세 설명 (선택) |
| source | TEXT | 출처 (사용자입력/자동) |

### API

```
GET /api/catalysts?stock_code=403870&days=90
POST /api/catalysts  {stock_code, event_type, event_date, title, description?}
PUT /api/catalysts/{id}
DELETE /api/catalysts/{id}
```

## 6. 상태별 정책

| 상태 | 화면 |
|------|------|
| **이벤트 없음** | "예정된 이벤트가 없습니다" + 추가 버튼 |
| **과거 이벤트** | 회색 처리 (접이식, 기본 접혀있음) |
| **오늘 이벤트** | 강조 표시 (파란색 좌측 보더) |
