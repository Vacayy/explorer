## 0. 한 문장

**"읽기 폭 768px 한 컬럼, 어시스턴트는 말풍선 없이 문서처럼, 근거는 본문 번호와 카드가 연결되고, 과정은 답 위에 접혀 있다."**

## 1. 문제 (as-is, D-130~134 시점의 ChatPage)

| 증상 | 원인 | 결과 |
|---|---|---|
| 답변 한 줄이 100자를 넘음 | 본문이 셸 폭(1440−240px)을 다 씀 | 장문 종합의 가독성 저하 (권장 65~75자/줄) |
| 채팅앱처럼 보임 | 사용자=primary 말풍선, AI=hypothesis 틴트 말풍선 | "도구"가 아니라 "메신저"로 읽힘. 어시스턴트 답에 표·제목이 들어가면 말풍선 안에서 답답 |
| 인용이 본문과 끊김 | `[n]`은 본문에 텍스트로만, 칩은 아래에 따로 나열 | "이 문장의 근거가 뭐지"를 번호 대조로 찾아야 함 |
| 과정을 보려면 답 밑까지 내려가야 함 | 답변 경로 토글이 답 하단 | 긴 답에서 과정과 답이 멀어짐. 생성 중 status와 완료 후 경로가 다른 자리에 |
| 스크롤이 강제됨 | 새 조각마다 `scrollIntoView` | 위로 올려 앞 답을 읽는 중 끌려 내려감 (auto-scroll yank) |
| 복사·재질문 없음 | — | 답을 메모·논지에 옮기려면 드래그 선택 |
| 모바일에서 대화가 밀림 | 사이드바가 위에 스택 | 첫 화면이 스레드 목록 |
| 텍스트 10~11px 다수 | 밀도 우선 | 판독성 저하, 위계 없음 |

## 2. 방향 — 레퍼런스가 수렴한 것

1. **3영역 레이아웃**: 좌측 스레드 레일(접힘 가능) · 중앙 메시지 스트림(max-w 720~768) · 하단 고정 컴포저. 우측 패널은 없음(아티팩트 없음).
2. **말풍선 폐기(어시스턴트)**: 풀폭 마크다운 본문. 사용자 메시지만 옅은 배경으로 구분. "도구" 프레이밍.
3. **컴포저**: 내용에 맞게 성장(상한 후 스크롤), 전송 버튼은 입력 안 우측 하단, Enter 전송 / Shift+Enter 줄바꿈, 힌트는 아래 한 줄.
4. **스트리밍**: 끝에 캐럿, 상태는 답 위 한 줄. 사용자가 위로 스크롤하면 자동 스크롤 해제 + "최신으로" 플로팅 버튼.
5. **근거**: 본문 인라인 번호 칩(호버=제목, 클릭=이동) ↔ 하단 소스 카드(종류·제목). 검색 기반 답이면 소스를 반드시 보인다.
6. **과정 공개**: "Thought for Ns" 패턴 — 답 **위**에 접힌 한 줄(도구 N · 근거 M · N초). 생성 중엔 같은 자리가 라이브 status.
7. **메시지 액션**: 호버 시 복사·(사용자) 다시 질문. 모바일은 상시 노출.
8. **빈 상태**: 인사 + 중앙 컴포저 + 제안 카드(이 시스템이 잘하는 질문 유형별).
9. **스레드 목록**: 날짜 그룹(오늘/어제/지난 7일/이전), 검색, 자동 제목.

- **레일**: `lg` 이상 인라인 aside(토글로 접힘, 상태는 세션 내 useState). `lg` 미만은 헤더 [≡] → shadcn **Sheet(left)** 에 같은 `ThreadRail` 렌더. 항목 = 제목(1줄 truncate) + 채널 아이콘(텔레그램만) + 상대시각. 활성 = `bg-accent`. 검색은 클라이언트 필터(제목).
- **헤더**: 슬림 1줄. 레일 토글 · 제목 · 채널 배지 · 메시지 수. 새 대화가 아닐 때만.
- **중앙 컬럼**: `max-w-[768px]`. 스크롤 컨테이너는 메시지 영역만(컴포저 고정).
- **컴포저**: `rounded-2xl` 카드(ring), Textarea는 보더 제거 + `field-sizing-content` 성장(`max-h-48`), 전송 = `icon` 버튼(ArrowUp), 생성 중은 Spinner로 대체·비활성. 힌트 1줄 아래.

## 4. 메시지 렌더

### 사용자
우측 정렬, `max-w-[80%]`, `bg-muted rounded-2xl px-4 py-2.5`, 텍스트 `text-[15px]`. 호버 액션(아래 우측): 복사 · **다시 질문**(컴포저에 원문 프리필).

### 어시스턴트 (풀폭, 말풍선 없음)
1. **메타 행**: hypothesis 색 점(●) + "AI 종합" + 모델 + 상대시각. → LLM 산출=hypothesis 마커 규칙(DESIGN_SYSTEM §2)을 **틴트가 아닌 라벨**로 충족. D-018의 "AI 말풍선 틴트" 적용은 이 화면에서 해제(D-135).
2. **과정 행**(route 있을 때): Collapsible 트리거 `▸ 답변 경로 · 도구 N · 근거 M · 총 N초`. 펼치면 RoutePanel(steps → process → 요약 메타 → 도구 표, D-134 그대로).
3. **본문**: shared/Markdown, `text-[15px] leading-7`. **인라인 인용 칩**: 본문 `[n]`·`[n, m]`을 전처리로 `[n](#cite-n)` 링크로 바꾸고 Markdown `components.a`에서 `#cite-` 링크만 칩으로 렌더 — `n` 표기 소형 pill, Tooltip=종류·제목, 클릭=근거 href로 이동(href 없으면 no-op). 유효 번호 밖(citations에 없음)은 텍스트 그대로.
4. **갭 블록**(있을 때): hypothesis 8% 틴트 박스, 항목마다 `⚠ [유형] 메모`. 갭은 이 시스템의 일급 산출(D-004)이라 작게 숨기지 않는다.
5. **근거 카드 행**: "근거 N건" 라벨 + 카드 `[n] 종류 · 제목`(Link, 종류 라벨 매핑: 문서/내러티브/인과/지식/질문/렌즈/시세/시세 추이/국면/브리핑). 기본 6개, 나머지 "+N" 토글.
6. **액션 행**(호버, 모바일 상시): 복사(본문 마크다운 원문, toast "복사됨").

### 생성 중 (D-130 규약: 마지막 메시지=user ⇒ 생성 중)
- 메타 행 + **과정 행 자리에 라이브 status**(Spinner + "근거 수집 중 (search_docs)…").
- 본문: SSE delta가 있으면 Markdown + 끝 캐럿(▍ 점멸). 없으면 3줄 Skeleton.
- 폴링 2.5초·SSE 가속·5분 stall 판정은 기존 로직 유지(hooks/useChat.ts로 이동).
- **정지 버튼 없음** — 백엔드에 취소 API가 없다(백로그).

### 스크롤 규칙
- 스크롤 컨테이너 하단 80px 이내 = "바닥". 바닥일 때만 새 조각·새 메시지에 자동 스크롤.
- 바닥이 아니면 우하단 플로팅 `↓ 최신으로`(rounded-full, shadow) 표시.
- 스레드 전환·내 질문 전송 직후는 무조건 바닥으로.

## 5. 5-state

| 상태 | 표시 |
|---|---|
| **Empty** (id 없음) | 중앙 인사 "무엇을 확인할까요?" + 한 줄 설명 + **컴포저를 중앙에** + 제안 카드 4장(최근 이슈 / 시세 흐름 / 내러티브·인과 / 가설 대질 — 클릭=프리필). 레일 비었으면 "아직 대화가 없습니다 — 텔레그램 봇 문답도 여기 쌓입니다" |
| **Loading** | 레일: 항목형 Skeleton 4줄. 스레드: 사용자 1 + 어시스턴트 1 형태의 Skeleton |
| **Partial** | 생성 중 = 위 "생성 중" 렌더(status·초안·캐럿). 다른 화면에 다녀와도 서버 상태로 복구 |
| **Error** | 스레드 로드 실패: shared/ErrorState + 재시도. 질문 전송 실패: 컴포저 위 destructive 한 줄 + 입력 보존. stall(5분): 인라인 안내 "생성이 멈춘 것 같습니다 — 서버 확인 후 다시 질문" |
| **Ideal** | §4 |

## 7. 기각·보류

- **스레드 이름 변경·삭제·고정** — API 없음(conversations에 PATCH/DELETE 부재). FE만 바꾸는 이번 범위 밖 → BACKLOG.
- **정지(stop generating)** — 백그라운드 태스크 취소 경로 없음 → BACKLOG.
- **재생성·👍👎 피드백** — 평가는 scripts/eval_chat.py로 오프라인. 대화 안 피드백은 저장 테이블이 없어 보류.
- **우측 소스 패널(ChatGPT식)** — 근거가 내부 링크(문서·내러티브·온톨로지)로 각자 목적지가 있어 카드+이동으로 충분. 1인 도구에 패널 하나 더는 과함.
- **레일 상태 localStorage 저장** — 세션 useState로 충분. 요구 시 추가.
