## 1. 문제 — 왜 개편하나

현재 `/knowledge`는 **세계관 요약 카드 + 지식 항목 평면 리스트**뿐이다. 문제:
- 시스템의 지식이 *어떤 구조로* 만들어지는지(3계층·수명주기·pace 층) 페이지에서 알 수 없다.
- *현황*(상태·층별 분포, 승격 대기 큐, 충돌 중)을 조망할 수 없다.
- 사용자 지식 주입이 대화의 "기억해:" 프리픽스로만 가능하고, 내가 넣은 지식이 **지금 어느 단계인지·삭제**가 UI에 없다.

목표: 이 페이지 하나로 **(a) 체계의 구조를 학습하고 (b) 현황을 관측하고 (c) 내 지식을 주입·추적·삭제**한다.

## 2. 개념 축 — salience × conviction (신규)

지식 항목을 두 직교 축으로 위치시킨다. "반복=지식"의 함정을 피하고, *시장 주목*과 *진리근접도*를 분리해 그 갭 자체를 신호로 삼는다(설계 §G).

- **conviction(확신)** = 근거의 강도. 입력: 독립 지지 관측 수(릴레이 접힘 반영) − 반박(refute) 가중 · 소스 유형 다양성 · pace 층 가중(structure/regime↑, 느린 진실) · (K1+: 소스 국지성/트랙레코드).
- **salience(주목)** = 시장이 지금 이걸 얼마나 회자하나. 입력: 지식 주체 엔티티의 최근 창 언급량 + 최근 증거 타임스탬프 밀도(activation의 최신성 항).

4상태(임계로 분류, 라벨 확정):

| | 확신 낮음 | 확신 높음 |
|---|---|---|
| **주목 높음** | **확신 대비 과한 주목** (진자 경고) | **주목받는 확신** (선반영·엣지 소진) |
| **주목 낮음** | **단순 노이즈** (무시) | **주목받지 않은 확신** (기회·소외된 엣지) |

각 지식 카드에 이 상태를 배지+2×2 미니 위치로 표기. (홈의 "통념 vs 나의 가설" 갭 패널은 P2 — 본 스펙 범위 밖.)

## 3. 반증-우선 주입 (하이브리드: 구조화 + Opus)

사용자가 지식을 주입하면 **수동으로 corroboration을 기다리지 않고**, 즉시 반증 조건을 생성해 "이게 틀리려면 무엇이 참이어야 하나"를 함께 보여준다(ACH 능동형).

- **생성(Opus, 1회)**: 주입 즉시 opus가 반증 조건 2~3개를 **관측 가능한 구조**로 산출 —
  `{condition(서술), target_entity, metric, threshold, window}`. `knowledge_falsifiers`에 적재.
- **감시(LLM 0, 결정적)**: 생성된 조건을 기존 신호·검색 파이프라인이 매 회차 확인.
  충족 시 `knowledge_falsifiers.triggered_at` 기록 → 해당 지식 refute 증거 부착 → `contested` 전환.
- **동시에** `_seed_evidence`(기존)로 지지/반박 문서 탐색 → 독립 지지 2+면 corroborated.

즉 주입은 자유롭되, **반례가 쌓이면 corroborated로 못 올라가고 contested로 강등** — 시스템 지식과 같은 수명주기·같은 기준.

## 4. 화면 구성 (위→아래)

최상위 `shared/PageContainer`. URL: `/knowledge` (기존 유지). 3개 논리 섹션.

### 4-1. 구조 지도 (범례 — 접이식 Collapsible, 기본 펼침 1회 후 접힘 기억)
- 3계층 흐름: `원문서(records) → 주장(claims) → 지식(knowledge)` 한 줄 다이어그램.
- 수명주기 파이프: `관측됨 → 교차확인 → (충돌) → 폐기` + `가설(내 주입)`.
- pace 5층 범례: event/flow/cycle/structure/regime (느릴수록 오래 사는 지식).
- 정적 콘텐츠(LLM 0). "이 시스템이 지식을 어떻게 만드나"의 학습용.

### 4-2. 현황 대시보드
- 카운트 스트립: 총 지식 · 교차확인 N · 충돌 중 N · 승격 대기 N · 내 주입 N.
- **승인 대기 큐**(review_status='proposed'): 항목별 인라인 승인/거부(기존 approve/reject API).
- 세계관 카드(기존 WorldviewCard 유지).
- 지식 리스트: 기본 activation 순. 필터칩 — 상태(교차확인/충돌/가설)·pace 층·salience×conviction 4상태. 각 카드: statement · 층 배지 · 상태 배지 · **salience×conviction 위치** · 근거 해부(독립 지지 N/반박 M/소스 다양성) · 반증 조건 · 근거 문서(펼침).

### 4-3. 내 지식 (주입 콘솔)
- 주입 input: statement(필수) + 근거/출처(선택, "왜/누가") + 사실/가설 토글.
- 제출 → 낙관적 append → 백그라운드로 반증 조건·근거 탐색.
- **내 주입 큐**: 내가 넣은 지식만, 수명주기 단계 뱃지(가설 → 교차확인 대기 → 교차확인됨 / 충돌). 각 항목 반증 조건 노출.
- **삭제**: 내 주입 지식은 '나의 가설'(vault 소유권)이라 삭제 허용 (AlertDialog 확인). 단 시스템이 승격한 지식은 삭제 불가 — superseded만(계보 보존).

## 5. 5-state

| 상태 | 처리 |
|---|---|
| **Empty** | 지식 0건: 구조 지도는 항상 노출 + 주입 콘솔에 "첫 지식을 주입해보세요" CTA. 대시보드 리스트는 "수집이 쌓이면 승격됩니다" 안내. |
| **Loading** | 카운트 스트립·카드 리스트 스켈레톤(기존 KnowledgeSkeleton 재사용·확장). |
| **Partial** | 세계관(느림, opus)은 스켈레톤 유지한 채 리스트·대시보드 먼저 렌더. 주입 직후 반증 조건 생성 중이면 해당 카드에 "반증 조건 생성 중…" 인라인. |
| **Error** | 리스트 fetch 실패 시 ErrorState+재시도. 주입/삭제 실패는 toast + 낙관적 롤백. 반증 생성 실패는 조용히 생략(지식 자체는 저장됨). |
| **Ideal** | 구조 지도(접힘) → 대시보드(카운트·큐·리스트) → 내 주입 큐. activation 상위·충돌 중이 눈에 띔. |

## 6. 백엔드 변경

### 신규/변경 API (`routers/spine_knowledge.py`)
- `POST /api/spine/knowledge` (기존 inject 확장) — body에 `rationale`·`source` 추가, 주입 후 반증 조건 생성 트리거.
- `GET /api/spine/knowledge/items` (기존) — 응답에 `salience`·`conviction`·`quadrant`·근거 해부(indep_support/refute/source_types)·falsifiers 추가.
- `GET /api/spine/knowledge/overview` (신규) — 카운트 스트립·상태/층 분포.
- `DELETE /api/spine/knowledge/items/{id}` (신규) — 내 주입(model='user') 한정, 시스템 승격분은 403.
- `GET /api/spine/knowledge/items/{id}/falsifiers` (신규) — 반증 조건 목록·triggered 여부.

### 파이프라인
- `pipeline/knowledge.py` — `inject_knowledge`에 rationale/source 저장 + 반증 조건 생성 호출.
- `pipeline/falsifiers.py` — 반증 조건 생성 모델을 **opus**로, 산출을 구조화(`target_entity·metric·threshold·window`)로 강화. 감시는 기존 결정적 로직 유지.
- salience/conviction 계산 — `pipeline/knowledge_recall.py` 또는 신규 `knowledge_state`에 순수 함수(LLM 0). knowledge_evidence 집계 + 엔티티 최근 언급량.
- DB: `knowledge`에 `rationale·source_ref` 컬럼, `knowledge_falsifiers`에 `target_entity·metric·threshold·window` 컬럼 (ALTER 패턴).

## 7. 구현 단계

- **P0** 지식 페이지 3섹션(구조 지도·대시보드·주입 콘솔) + 삭제 + overview API + items 근거 해부.
- **P0** 반증-우선 주입(opus 구조화 생성 + 결정적 감시).
- **P1** salience×conviction 계산·4상태 배지.
- **P2** (범위 밖) 홈 "통념 vs 나의 가설" 갭 패널 · 소스 트랙레코드 가중(K1+ 국지성).
