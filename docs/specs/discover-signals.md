# 화면 기획서: 시그널 피드

> 경로: `/discover/signals`
> 상태: 기획 완료, 구현 대기

---

## 1. 목적

워치리스트/관심 종목에 대한 **주요 이벤트를 한 곳에서 모니터링**한다.
매일 아침 "어제 뭐가 있었나?"를 이 화면으로 확인.

---

## 2. 시그널 소스 (v1)

| 시그널 타입 | 소스 | 아이콘 | 설명 |
|-----------|------|-------|------|
| 공시 | DART disclosures | 📋 | 주요 공시 (실적, 계약, 증자 등) |
| 내부자 거래 | DART 지분공시 (kind=D) | 👤 | 임원/대주주 매수/매도 |
| 대규모 계약 | DART 주요사항 (kind=B) | 📝 | 공급계약, 시설투자 |

### v2 확장 예정
- 거래량 이상치 (전일 대비 3배 이상)
- 실적 서프라이즈 (컨센서스 대비 Beat/Miss)
- 52주 신고가/신저가

## 4. 시그널 항목 구조

| 필드 | 표시 |
|------|------|
| 타입 아이콘 | 📋 / 👤 / 📝 |
| 기업명 | 볼드, 클릭 → /analyze/:stockCode/summary |
| 이벤트 요약 | 공시명 또는 가공된 요약문 |
| 시간 | 접수 시간 |
| 원문 링크 | DART URL (외부 링크 아이콘) |

### 기업명 클릭 동작
- 클릭 → `/analyze/:stockCode/summary` 이동 (기업 분석)
- 워치리스트 종목은 종목명 옆에 ★ 표시

---

## 5. 필터 정책

| 필터 | 옵션 | 기본값 |
|------|------|-------|
| 대상 | 전체 / 워치리스트만 | 워치리스트만 |
| 기간 | 오늘 / 최근 7일 / 최근 30일 | 최근 7일 |
| 시그널 타입 | 전체 / 공시 / 내부자거래 / 대규모계약 | 전체 |

- 워치리스트가 비어있으면: "전체" 모드로 자동 전환 + 안내 메시지

---

## 6. 상태별 정책

| 상태 | 화면 |
|------|------|
| **워치리스트 비어있음** | "워치리스트에 종목을 추가하면 해당 종목의 시그널을 모아볼 수 있습니다" + 워치리스트 이동 링크 |
| **시그널 없음** | "최근 {기간}에 시그널이 없습니다" |
| **로딩** | 카드 스켈레톤 3개 |
| **에러** | "시그널을 불러올 수 없습니다" + 재시도 |

## 7. 데이터 모델

### API Endpoint

```
GET /api/signals
  ?stock_codes=403870,272110,036930    (콤마 구분, 없으면 전체)
  &days=7
  &type=all|disclosure|insider|contract
  &page=1
  &size=50
```

### Response Shape
```json
{
  "items": [
    {
      "type": "disclosure",
      "stock_code": "403870",
      "corp_name": "HPSP",
      "title": "[주요사항보고]반기보고서 제출",
      "date": "2026-06-15",
      "time": "15:30",
      "url": "https://dart.fss.or.kr/...",
      "in_watchlist": true
    }
  ],
  "total": 12
}
```

### 구현 방식
- 별도 테이블 불필요 — `disclosures` 테이블을 워치리스트 종목 기준으로 조회
- `kind` 매핑: B=주요사항(대규모계약), D=지분(내부자거래), 나머지=일반공시
- 정렬: 날짜+시간 내림차순
