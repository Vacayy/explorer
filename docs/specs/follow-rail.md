# 팔로우 레일 — 사이드바 통합

## 배경
워치리스트(종목)·구독 채널·구독 블로그는 전부 "내가 팔로우하는 대상"이라는 같은 프리미티브인데,
사이드바가 라우트에 따라 두 얼굴(/feed=소스, 그 외=워치리스트)이고 클릭 행동·비주얼·코드가 3벌로 분산.
(진단: 위치 분산 / 클릭 불일치 — 소스 행은 클릭해도 이동 없음 / row 해부학 제각각)

## 결정 (stakeholder 승인)
**단일 팔로우 레일** — 모든 화면에서 같은 사이드바. 섹션 3개 접이식: 종목 / 채널 / 블로그.

## Row 해부학 (공통)
```
[상태] 이름            ← 상태: 소스 경고점(7일 유입 0) · 종목 conviction 별점
보조줄                 ← 종목: 종가+갭 / 채널: 7일 N건 / 블로그: 저자 · 7일 N건
hover: 우측에 토글(소스 on/off) 노출
클릭: 해당 도시에로 이동 (종목→/analyze/:code/summary, 소스→/source?kind=&key=)
active: 현재 보고 있는 대상이면 좌측 보더 + 배경 강조
```

## 섹션 헤더
`▾ 제목 N [+]` — 접이식(로컬 상태), [+]는 종목=워치리스트 관리 페이지로, 채널/블로그=인라인 추가 폼 펼침
(추가 폼은 기존 spine 등록 API 재사용: 실검증 + 백그라운드 첫 수집)

## 5-state
- Empty: 섹션별 "아직 없음 — +로 추가" 한 줄
- Loading: 섹션별 Skeleton
- Partial: health 조회 실패 시 보조줄 "-" (목록은 정상)
- Error: 섹션별 조용히 빈 상태 (사이드바는 보조 UI — 전면 에러 금지)
- Ideal: 3섹션 목록
