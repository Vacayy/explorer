# 홈과 통합 피드

상태: 구현됨 · 상위: [SYSTEM](../SYSTEM.md), [디자인 시스템](../DESIGN_SYSTEM.md). 홈/피드의 현행 계약은 이 문서에서 관리한다. 과거 product-v2/v3의 스트림 제안과 일별 개편 문서를 추가로 유지하지 않는다.

## 목적과 화면 — D-153 전체 폭 모드

승인된 [HTML 기획안](../prototypes/home-mode-reader.html)을 적용한다. Home 헤더의 `시장 / 피드` 전환은 모든 화면에서 노출한다. 첫 방문은 시장, 이후 마지막 모드를 복원하며 명시적 `home_view` URL이 우선한다. 시장 지수는 두 모드 공통 한 줄 캐러셀이다. 최상단은 S&P500·나스닥·코스피·코스닥·항셍·니케이225·대만증시(TAIEX) 순이다. 값은 16px, 미니 추이는 20px로 압축하며 데스크톱 한 줄, 좁은 화면에서는 가로 스크롤한다. 다우는 홈 스트립에서 제외하며 기존 저장 데이터는 유지한다.

- 시장: 시장 국면 요약 → 미국장 브리핑 → 국장 거래대금(전체 폭) → 주목 주제/언급 모멘텀 → AI가 최근 만든 것/내러티브 → 종목 요약/최근 리포트 → 인과 그래프 업데이트(전체 폭). 각 쌍은 별도 행이며 가용 폭 1000px 미만에서는 같은 순서로 세로 배치한다. 순위 카드는 상위 5개와 전체 보기 링크를 제공한다.
- 피드: 300px 소스 디렉터리 + 나머지 폭의 연속 게시물 리더. 데스크톱 목록/본문 독립 스크롤, 짧은 화면은 페이지 스크롤. 모바일은 목록 → 본문 → 목록 복귀.
- 소스 목록: 전체 업데이트, 활성 텔레그램/블로그/유튜브, 저장된 기업/인물 요약 및 컨콜/수출입. 최신 시각·발췌·저장 건수를 표시한다. 건수는 읽지 않은 알림 수가 아니다. 검색과 플랫폼 필터는 전체 디렉터리에 적용한다. 종류 버튼은 줄바꿈 없이 한 줄 가로 스크롤한다. 목록은 아바타 없는 최소 72px 행, 선택은 배경색으로만 표시한다(왼쪽 테두리 없음). 게시물 상하 여백은 20px로 밀도를 맞춘다.
- 리더: 원문 기본, 저장 요약 선택. 사용자 피드백에 따라 일반 본문은 14px/22px, 제목은 본문보다 크게 유지한다. 요약이 없으면 빈 상태를 설명하며 조회 시 생성하지 않는다. 시스템 게시물은 원문 발언과 구분하고 생성 여부·근거 수·기준 기간을 유지한다. 최신순과 명시적 페이지 이동, 조회 상한을 유지한다.
- Home 피드 진입 시 팔로우 레일은 기본 접힘. 사용자의 수동 토글은 가능하며 시장/다른 페이지는 이전 상태 복귀.
- URL: `home_view`, `channel`, `reading`, `reader_page`, `reader_until`, `reader_open`. 목록 검색/종류도 URL 보존. 모드 전환 시 선택·스크롤 복원.
- `/feed` 기본 진입은 `/home?home_view=feed`로 이동한다. 기존 `feed_*` 타임라인 필터 및 문서 검색/태그 URL은 유지한다. 메시지 전송·조회수·반응·읽음 동기화는 포함하지 않는다.

`AI가 최근 만든 것`은 지난 7일간 생성된 내러티브·리포트·파급·종목 요약과 **완료된 유튜브 AI 정리본**을 최신순으로 함께 표시한다. 유튜브 행은 `유튜브 요약` 배지와 영상 제목을 보여주고 `/doc/:id?reading=digest`로 연결한다. 생성 시각은 성공한 `youtube_digest_jobs.updated_at`을 사용하며, 작업 기록이 없는 기존 정리본은 본문 저장 시 갱신된 `raw_documents.fetched_at`을 사용한다. 영상 게시일이나 짧은 enrichment 생성일을 정리본 생성일로 사용하지 않는다. 미생성·실패·본문 없는 영상은 제외하며, 목록 조회는 저장 자료만 읽는다.

## Home 중심 탐색과 시장 요약 (D-155)

Dock은 Home·관심목록·월드모델·대화 4개이며 피드 읽기는 Home으로 통합한다. `/follow`는 관심 기업·인물·산업·테마, `/sources`는 기존 텔레그램·블로그·RSS·유튜브 소스 관리다. Home 피드의 소스 관리, 더보기, 검색에서 접근한다. 문서 검색은 `/feed?view=documents`에 유지한다.

시장 모드에서는 공통 지수 캐러셀 다음, 미국장 브리핑 위에 `MarketContext` 요약 띠를 표시한다. VIX·공포탐욕·미국 2Y/10Y 금리·달러원·WTI·금·비트코인을 값과 개별 관측일로 표시하며 좁으면 가로 스크롤한다. 기본은 접힘, 상세에서 기존 시장 국면·매크로 카드를 펼친다. 펼침 상태는 로컬 설정에 보존한다. 고정 헤더로 만들지 않으며 피드 모드에는 표시하지 않는다. 기존 하단 중복 카드는 제거한다. 저장값과 해석을 구분하고 미수집·실패 상태를 표시한다.

지표 hover 시 `MetricTrend` 버블에서 저장 관측의 추이를 표시한다. 클릭/터치/Enter로도 열리고 Escape로 닫힌다. 버블에 포인터를 옮겨도 유지되며 화면 가장자리를 벗어나지 않는다. 관측 시작/끝 날짜·최저/최고·개수를 표시하고, 관측이 부족하면 차트를 만들어내지 않는다. 매크로 API `dated_series`는 실제 관측일과 값을 함께 반환한다.

검증: 실제 저장 데이터로 요약/펼침/복원, 피드 제외, 소스 관리 분리, 기존 검색/필터 URL, Alt 단축키, 모바일·다크·가로 넘침을 확인했다. 브라우저 조회에서 POST 요청 및 JS 오류 0건. 백엔드 테스트 50개와 프론트엔드 빌드 통과. 산출물은 `logs/dock-market/`에 보존한다.

## 소스 디렉터리 계약

`GET /api/spine/feed/channels`는 동일한 활성 소스/시스템 투영 전체를 SQL 집계한다. `id`, `name`, `platform`, `count`, `latest_at`, `preview`를 반환하며 빈 활성 구독도 포함한다. `timeline?channel=...`은 페이지 제한 전에 해당 채널/기업 ID/인물 키/컨콜 ticker/수출입 그룹을 필터한다. 첫 페이지 클라이언트 필터를 사용하지 않는다. 새 저장소나 수집/생성 작업은 추가하지 않는다.

## 조사와 적용 판단 (2026-09-10)

- [Feedly: 보기·밀도 설정](https://docs.feedly.com/article/276-how-do-i-change-the-views-of-my-feeds-and-source): 텍스트·매거진·카드 및 밀도 옵션을 제공한다. 이 제품에서는 차트와 함께 읽으므로 이미지 중심 그리드보다 세로 카드, 두세 줄 미리보기와 간결한 보기 선택을 채택한다.
- [Linear Inbox](https://linear.app/docs/inbox): 구독 대상의 업데이트를 모으고, 종류/우선순위와 개별 항목의 상세 확인을 제공한다. 여기서는 원문과 시스템 업데이트를 구분하며, 중요도 점수를 임의로 만들지 않는다. 승인 요청은 기존 승인함에 둔다.
- [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md): 키보드·포커스·라벨·URL 상태·긴 콘텐츠·반응형 점검에 적용한다.

기존 `/feed`의 미리보기 위계(D-151): 출처/Explorer + 유형 + 시각 → 읽을 수 있는 제목 → 내용 미리보기 → 대상/자료 수/기준 기간 → 상세·원문. 채널 이름을 인물의 직접 발언자로 취급하지 않는다. 원문에서 생성한 요약은 `AI 요약`, 시스템 해석은 hypothesis 토큰으로 표기한다. 기존 타임라인의 이미지는 작은 미리보기, 본문은 명시적으로 펼친다. D-153 Home 리더는 원문 본문·첨부를 바로 읽으며, 시스템 대상에서는 원문/요약 전환 대신 저장 업데이트임을 표시한다.

## 데이터 계약

`GET /api/spine/feed/timeline`: 읽기 전용 통합 투영. 기존 테이블 및 수집/생성 파이프라인을 보존한다. GET에서 LLM·수집·백필을 실행하지 않는다.

| 종류 | 저장 원천 | 노출/묶음 기준 | 시간 의미 |
|---|---|---|---|
| 소스 글 | raw_documents + enrichments | 활성 Telegram/블로그/YouTube 구독, 기존 원문 링크·이미지·태그 | 게시 시각, 없으면 수집 시각 |
| 기업 요약 | entity_digests + entities | 기업·기간·구간당 1개, 저장된 요약 | 생성 시각 + 별도 기준 구간 |
| 인물 요약 | source_digests(kind=person) | 저장된 인물 프로필당 1개 | 생성 시각, 직접 발언/거래로 단정하지 않음 |
| 컨콜 | transcripts + transcript_follow | 활성 구독, 콜당 1개. 원문 피드와 중복하지 않음 | 수집 시각 + 별도 회계분기(실제 콜 날짜 추정 금지) |
| 수출입 | trade_stats + trade_follow | 활성 품목별 최신 통계월만, 월당 묶음 1개(과거 백필 제외) | 수집 시각 + 통계 기준월. 갱신/재수집을 새로운 발표로 단정하지 않음 |

회사·인물 요약은 이미 생성된 시스템 커버리지를 표시한다(개인 팔로우 한정이라고 표기하지 않는다). 요약 없는 인물을 예시로 만들어 채우지 않는다. 요약 생성의 자동화 범위는 별도 과제다.

안정 ID는 원천 ID/월 기준. 시간은 UTC 정규화 후 정렬, 동률은 ID로 확정. 페이지 이동은 조회 상한 시각을 고정해 신규 유입에 따른 밀림을 줄인다. 저장 요약의 교체까지 불변 스냅샷으로 보장하지 않는다. 잘못된 필터/페이지는 검증한다. 실데이터 없는 종류는 빈 상태로 설명한다.

## 상태와 검증

- 로딩: 피드 자체 skeleton. 한쪽 실패가 다른 쪽/시장 스트립을 가리지 않는다.
- 빈 결과: 선택한 종류에 저장된 업데이트 없음, 필터 초기화/소스 관리 동선.
- 오류: 재시도. 재조회 실패 시 기존 자료는 남기고 경고.
- 부분: 기존 타임라인의 요약 없음은 원문 발췌로 표시. Home 리더의 요약 보기에서는 요약 없음과 원문 확인 동선을 설명한다. 자료 수는 저장 메타의 수이며 독립 출처 수로 과장하지 않는다.
- 검증: SQLite fixture로 활성 소스/뮤트, 종류 분리, 중복/페이지/시간, 빈 요약/수출입 묶음, 읽기 전용. 데스크톱/레일/모바일 시각 점검 + 키보드/URL 상태, 기존 문서 검색 호환, TypeScript/build.

## 국장 거래대금 이유 브리핑 보완

전체 폭 카드에서 상위 20종목 합계·상위 섹터 비중·거래대금 1위를 짧게 설명하고, 섹터 쏠림/개별 이슈와 상위 5종목 관련 자료를 좌우 배치한다. 기존 상위 20 전체 펼침과 갱신 버튼은 유지한다.

`GET /api/spine/kr/movers`에 `briefing`을 추가한다. 저장 스냅샷 당일까지 3일(KST 발행일) 범위에서 기업 엔티티로 연결된 문서 최대 2건/종목을 반환한다. 최신 enrichment 한 건만 조회하고, 회사명이 들어간 저장 요약 문장 또는 원문 문장을 제한 발췌한다. 원문/AI 요약 출처를 구분하며 전체 문서의 무관한 요약을 종목 이유로 붙이지 않는다. 우선주는 본주 관련 자료 포함을 표시한다. 관련 자료는 가격 움직임의 입증된 원인이 아니며, 자료 없으면 추가 확인 필요를 표시한다. 새 LLM 호출·수집·테이블은 추가하지 않는다.

날짜는 기존 FDR 저장 스냅샷 날짜를 그대로 표시한다. 이 날짜가 실제 거래 세션 날짜라고 새로 보장하지 않는다. 비중의 분모는 시장 전체가 아닌 상위 20종목이다.

대만 지수는 [Yahoo Finance ^TWII](https://finance.yahoo.com/quote/%5ETWII/chart/), 세션은 [TWSE 안내](https://www.twse.com.tw/en/about/company/service.html)의 현지 09:00–13:30을 사용한다. 기존 공휴일 미반영 표시는 유지한다.

## 유튜브 상세 읽기 (D-157)

피드 미리보기의 짧은 enrichment 요약과 긴 opus 영상 정리본은 서로 다른 산출물이다. `/doc/:id`의 유튜브 기본 탭은 **AI 정리본**, 다른 탭은 **원본 자막 / 짧은 요약**이다. 기존 `reading=original` 링크도 AI 정리본으로 연결한다. GET은 저장 조회만 수행한다. 아직 미생성인 영상을 열면 별도 POST로 작업을 접수하며 본문 탭은 즉시 이용할 수 있다. 생성 중 2초 폴링, 완료 시 정리본 표시, 실패는 설명과 재시도 버튼을 제공한다. 인증 실패를 자동 반복하지 않는다.

자막은 새 생성 시 `youtube_digest_jobs.transcript`에 보존한다. 레거시 성공 영상은 자막을 덮어썼으므로 원본이 없는 상태를 정직하게 표시한다. 상세의 정리본 생성은 기존 스터디의 고정된 본문·하이라이트를 바꾸지 않는다. 백엔드 재시작 등으로 1시간 이상 중단된 작업은 재시도할 수 있다. 수집 시 전량 정리 금지는 유지한다.
