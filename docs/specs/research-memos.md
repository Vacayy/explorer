# 화면 기획서: 투자메모

> 경로: `/research/memos`
> 상태: 기획 완료, 구현 대기

---

## 1. 목적

투자 논점을 **구조화된 형태로 기록**하고, 시간이 지나도 **왜 이 종목을 샀는지/안 샀는지** 추적 가능하게 한다.

현재 IR Notes(자유 텍스트 메모)를 2가지 뷰로 확장:
- **구조화 뷰**: Bull/Bear/Catalyst/Risk 4섹션
- **자유 메모 뷰**: 기존 자유 텍스트 (컨퍼런스콜 요약, 미팅 노트 등)

---

## 2. User Flow

```
투자메모 진입 (/research/memos)
  → 상단 기업 선택 드롭다운 (워치리스트 종목 위주)
  → 기업 선택
  → 2개 서브탭: [투자논점] [자유메모]
  │
  ├── [투자논점] 탭
  │   → Bull Thesis / Bear Thesis / Catalysts / Risks 4개 섹션
  │   → 각 섹션에 항목 추가/수정/삭제
  │   → 한눈에 투자 판단 근거 파악
  │
  └── [자유메모] 탭
      → 기존 IR Notes 동일 (날짜 + 제목 + 본문)
      → 컨퍼런스콜 메모, 미팅 노트, 자유 기록
```

## 4. 컴포넌트 상세

### 4-1. 기업 선택 드롭다운
- 데이터 소스: 워치리스트 종목 + 최근 조회 종목
- 워치리스트 종목 우선 표시 (구분선)
- 검색 가능한 드롭다운 (combobox)
- 선택 시 해당 기업의 메모 로드

### 4-2. 투자논점 4섹션

| 섹션 | 아이콘 | 색상 | 설명 |
|------|-------|------|------|
| Bull Thesis | 🟢 | emerald | 투자해야 하는 이유 |
| Bear Thesis | 🔴 | rose | 투자하면 안 되는 이유 |
| Catalysts | 📋 | blue | 향후 주가 촉매 이벤트 |
| Risks | ⚠️ | amber | 주의해야 할 리스크 |

각 섹션:
- 항목 목록 (bullet list)
- 항목별: 텍스트 내용 (1~2줄)
- [+ 추가] 버튼 → 인라인 텍스트 입력 → Enter로 저장
- 각 항목 호버 시 수정/삭제 아이콘 표시
- 드래그 앤 드롭: 미지원 (v1)

### 4-3. 자유메모 탭
기존 IR Notes 동일:
- 날짜 + 제목 + 본문 (textarea)
- 생성 / 삭제
- 날짜 내림차순 정렬

## 6. 데이터 모델

### 기존 `ir_notes` 테이블 확장

```sql
ALTER TABLE ir_notes ADD COLUMN memo_type TEXT DEFAULT 'general';
-- memo_type: 'general' (자유메모) | 'bull' | 'bear' | 'catalyst' | 'risk'
```

| memo_type | 용도 |
|-----------|------|
| `general` | 자유메모 (기존 IR Notes) |
| `bull` | Bull Thesis 항목 |
| `bear` | Bear Thesis 항목 |
| `catalyst` | Catalyst 항목 |
| `risk` | Risk 항목 |

- `title` 필드: 구조화 메모에서는 항목 텍스트로 사용
- `content` 필드: 구조화 메모에서는 상세 설명 (선택)
- `note_date` 필드: 구조화 메모에서는 작성일 자동 세팅

### API 확장

기존 `/api/ir-notes/{stock_code}` 엔드포인트에 `memo_type` 필터 추가:

```
GET /api/ir-notes/{stock_code}?memo_type=bull
GET /api/ir-notes/{stock_code}?memo_type=general
POST /api/ir-notes/{stock_code}
  body: { title, content?, note_date, memo_type: "bull" }
```

## 7. 인터랙션 상세

### 항목 추가
1. [+ 추가] 클릭 → 해당 섹션 하단에 텍스트 입력 필드 활성화
2. 텍스트 입력 → Enter 누르면 저장
3. Esc → 입력 취소
4. 저장 성공 → 목록에 즉시 반영 (Optimistic UI)

### 항목 수정
1. 항목 텍스트 클릭 → 인라인 편집 모드 (텍스트가 입력 필드로 변환)
2. Enter → 저장 / Esc → 취소

### 항목 삭제
1. 항목 호버 → 삭제 아이콘 (✕) 표시
2. 클릭 → confirm 없이 즉시 삭제 (구조화 메모는 짧은 텍스트이므로)
3. Optimistic UI + React Query 무효화

### 기업 전환
- 기업 드롭다운 변경 → 해당 기업의 메모로 즉시 전환
- 저장되지 않은 편집 중인 항목은 없음 (인라인 저장이므로)
