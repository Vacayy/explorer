# 화면 기획서: 워치리스트

> 경로: `/research/watchlist`
> 상태: 기획 완료, 구현 대기

---

## 1. 목적

투자자가 관심 종목을 **구조화된 형태로 관리**하고, 현재가 vs 목표가 갭을 한눈에 파악하여 **매매 타이밍 판단**에 활용한다.

기존 "검색 히스토리"(localStorage, 단순 목록)를 DB 저장 + 확신도/목표가/논점이 포함된 **투자 판단 도구**로 업그레이드.

---

## 2. User Flow

```
[진입 경로 1] 리서치노트 탭 → 워치리스트 서브탭
[진입 경로 2] 우측 사이드바 (모든 화면에서 접근 가능)
[진입 경로 3] 분석 페이지에서 "워치리스트에 추가" 버튼

워치리스트 진입
  → 종목 카드/테이블 스캔
  → 갭률(목표가 vs 현재가) 확인
  → 종목 클릭 → /analyze/:stockCode/summary 이동
  → 또는 확신도/목표가 수정 (인라인 편집)
```

## 4. 컴포넌트 상세

### 4-1. 워치리스트 테이블

| 컬럼 | 타입 | 정렬 | 포맷 | 비고 |
|------|------|------|------|------|
| 확신도 | ★ 1~5 | ✓ DESC | 별 아이콘 | 클릭으로 인라인 수정 |
| 종목명 | 텍스트 | ✓ | 볼드 | 클릭 시 /analyze 이동 |
| 종목코드 | 텍스트 | ✗ | 6자리 모노 | |
| 현재가 | 숫자 | ✓ | 원, 콤마 | 실시간 아님 (캐시된 최신 종가) |
| 목표가 | 숫자 | ✓ | 원, 콤마 | 미설정 시 "-" |
| 갭률 | 숫자 | ✓ DESC | +/-%, 색상 | (목표가-현재가)/현재가×100 |
| 시가총액 | 숫자 | ✓ | 억/조 | |
| 투자논점 | 텍스트 | ✗ | 최대 1줄, truncate | 호버 시 전체 표시 |
| 액션 | 버튼 | ✗ | 편집/삭제 | |

### 4-2. 종목 추가 폼

| 필드 | 타입 | 필수 | 기본값 | 유효성 |
|------|------|------|-------|--------|
| 종목 검색 | 자동완성 입력 | ✓ | - | companies 테이블에 존재 |
| 확신도 | 1~5 라디오/별점 | ✓ | 3 | 정수 1~5 |
| 목표가 | 숫자 입력 | ✗ | 빈값 | 0 이상 정수 |
| 투자논점 | 텍스트 입력 | ✗ | 빈값 | 최대 200자 |

### 4-3. 갭률 색상 정책

| 갭률 | 색상 | 의미 |
|------|------|------|
| +30% 이상 | 진한 초록 (emerald-600) | 강한 업사이드 |
| +10% ~ +30% | 초록 (emerald-500) | 업사이드 |
| 0% ~ +10% | 연한 초록 (emerald-400) | 소폭 업사이드 |
| -10% ~ 0% | 연한 빨강 (rose-400) | 소폭 다운사이드 |
| -10% 이하 | 빨강 (rose-600) | 목표가 하회 |
| 목표가 미설정 | 회색 | 미평가 |

## 6. 상호작용 정책

### 추가 정책
- 기업 검색으로 종목 선택 시: 워치리스트에 **자동 추가하지 않음** (명시적 추가만)
- 산업군/스크리너에서 종목 클릭 시: 분석 페이지 이동만, 워치리스트 추가 안 함
- 동일 종목 재추가: **기존 항목 업데이트** (중복 생성 안 함)

### 수정 정책
- 확신도: 별점 클릭으로 인라인 수정 (모달 없음)
- 목표가/논점: 행의 "편집" 버튼 → 인라인 편집 모드 전환
- 수정 저장: Enter 또는 포커스 아웃 시 자동 저장

### 삭제 정책
- 삭제 클릭 → confirm 다이얼로그: "HPSP를 워치리스트에서 제거하시겠습니까?"
- 삭제 후: 목록에서 즉시 제거 (Optimistic UI)
- Undo: 미지원 (v1)

### 사이드바 연동
- 풀페이지와 사이드바는 **같은 데이터 소스** (React Query 캐시 공유)
- 풀페이지에서 수정 → 사이드바 즉시 반영 (쿼리 무효화)

## 7. 데이터 모델

### DB 테이블: `watchlist`

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | INTEGER PK | AUTO | |
| stock_code | TEXT | UNIQUE, NOT NULL | 종목코드 |
| corp_code | TEXT | NOT NULL | DART 고유번호 |
| corp_name | TEXT | NOT NULL | 회사명 |
| conviction | INTEGER | DEFAULT 3, CHECK 1~5 | 확신도 |
| target_price | INTEGER | NULLABLE | 목표가 (원) |
| thesis | TEXT | NULLABLE, MAX 200 | 한줄 투자논점 |
| created_at | TEXT | DEFAULT now | 추가일시 |
| updated_at | TEXT | DEFAULT now | 수정일시 |

### API Endpoints

| Method | Path | Body | Response |
|--------|------|------|----------|
| GET | `/api/watchlist` | - | `WatchlistItem[]` (현재가, 시총 포함) |
| POST | `/api/watchlist` | `{stock_code, conviction?, target_price?, thesis?}` | `WatchlistItem` |
| PUT | `/api/watchlist/{id}` | `{conviction?, target_price?, thesis?}` | `WatchlistItem` |
| DELETE | `/api/watchlist/{id}` | - | `{ok: true}` |

### Response Shape: `WatchlistItem`
```json
{
  "id": 1,
```

## 8. 마이그레이션

### localStorage → DB 마이그레이션
- 앱 최초 로드 시, `localStorage("stock-explorer-history")`에 데이터가 있고 `watchlist` 테이블이 비어있으면:
  - 기존 히스토리 항목을 conviction=3, target_price=null, thesis=null로 마이그레이션
  - 마이그레이션 완료 후 localStorage 키 삭제
  - 콘솔에 "워치리스트 마이그레이션 완료: N건" 로그
- 이미 watchlist에 데이터가 있으면: 마이그레이션 스킵
