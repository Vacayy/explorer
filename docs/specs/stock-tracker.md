# 종목 추적 (2026-10-20 위젯 · 2026-11-05 관심 종목의 추적 표시 · 미국 티커 지원)

관심 묶음보다 한 단계 더 집중하는 추적이다. 관심 종목마다 '추적' 표시를 켜면 그 종목의 차트·기술적 신호, 수급, 이슈, 내 원칙 조건을 한 카드로 보이고, 조건이 충족되면 텔레그램으로도 알린다. 화면은 홈 › 내 종목(ia-redesign §4.4, 아래 '화면')과 종목 묶음 화면의 '추적' 스위치다.

> **배포 순서(필수)**: 이 계약(옛 원천 읽기 제거, 개편 3d 커밋)을 실사용 DB에 올리기 **전에** `scripts/migrate_tracking_to_groups.py --dry-run` → 실행을 끝낸다. 3d부터 `tracked_codes`는 홈 위젯을 읽지 않으므로, 이관하지 않은 위젯 종목은 알림이 소리 없이 멈춘다. 스크립트 출력의 '홈 위젯에만(이관 누락)'이 `-`여야 한다.

## 추적 대상 — 관심 종목의 추적 표시 (D-293, D-267 번복)
- **원천**: 관심(watch) 묶음 멤버의 `stock_group_members.tracked=1` 하나뿐이다(`stock_tracker.tracked_codes` = `member_codes`, 묶음·멤버 순서, 중복 없음). 홈 › 내 종목·종목 묶음 화면의 '추적' 스위치, `PUT /api/spine/groups/{id}/members/{code}/tracked`로 켜고 끈다. **국내 종목과 미국 티커 모두** 켤 수 있다(2026-11-05, D-297의 미국 차단 번복). 포트폴리오 묶음은 409.
- **옛 원천(홈 `track.stock` 위젯, `home_boards`) 읽기는 3d에서 제거했다.** 3a에서 홈 메뉴 화면이 없어져 위젯을 뺄 방법이 없었고(추적을 꺼도 알림이 계속되는 문제), 두 원천이 6=6으로 같음을 확인한 뒤 앞당겼다. 운영 점검 '추적 대상 두 원천 일치'(`tracker_sources`)와 토글 응답의 `widget_tracked`도 함께 없앴다.
- **일회 이관**: `scripts/migrate_tracking_to_groups.py [--dry-run] [--db]`(`stock_tracker.migrate_widget_tracking`, 멱등) — 위젯 종목이 기본 관심 묶음 '관심 종목'에 없으면 추적 표시와 함께 넣고, 있으면 표시만 켠다. 위젯·`home_boards`는 건드리지 않는다. `widget_codes`·`source_diff`는 이 스크립트만 쓴다.
- **남은 순서**: 백업 후 `home_boards` 정리(7단계).
- 추적 종목은 수급 수집 대상(`flows.collect_flows`)에 관심 묶음과 함께 들어간다(미국 티커는 수급 자료가 없어 수집 실패로 센다 — 관심 묶음과 같음).

## 미국 티커 추적 (2026-11-05)
- **시세**: `us_prices` 일봉(yfinance 캐시, `us_data.fetch_prices` 20시간 TTL). 실시간 시세가 없어 카드의 현재가는 마지막 미국 종가(`source='close'`), 카드 `market='us'`.
- **조건**: 같은 다섯 유형을 쓴다. 가격(`price_*`)은 달러 기준가, 이평선(`close_*_ma`) 값은 센트 단위(`ref` 소수 2자리), 확인 항목은 그대로.
- **판정 시점**: 국내 장중(30분 점검)에는 미국장이 닫혀 있어 판정하지 않는다. **국내 장 마감 점검(close)** 때 미국 일봉 캐시를 갱신하고(`_refresh_us`, TTL 안이면 건너뜀) 마지막 미국 종가로 가격·이평선 조건을 함께 판정한다. 중복 방지 키는 `track-cond:{미국 거래일}:{조건 id}` — 같은 미국 봉으로 두 번 보내지 않는다.
- **없는 것**: ±5%p 급등락(실시간 시세 없음), 공시(DART), 수급(투자자별), 원화 목표주가 언급. 새 기술적 신호는 `technical_scan`을 `us_prices`로 돌려 장 마감 점검 때 보낸다.
- **문구**: 이름 뒤에 `(티커·미국)`, 가격은 `$1,234.56`, 조건 문구 끝에 `· MM-DD 종가`. 예: `🛑 🔭 SiTime (SITM·미국) 조건 충족 · 손절선 (기준 $450.00) · 현재 $403.27 · 11-04 종가`.

## 충족 요약 (`GET /api/spine/tracker/status`, LLM 0 · D-301)
추적 종목 전체(`tracked_codes`, 국내·미국)의 조건 판정만 돌려준다 — `items[]` = code·name·market·as_of(판정에 쓴 시세 시각)·met·newly_met·conditions[id·role·label·status·newly_met], 합계 `met`·`newly_met`. 판정은 카드와 같은 `evaluate`·`newly_met`(시세 = 국내 `stock_prices`·장중 `portfolio_quotes`, 미국 `us_prices`)이고 차트·기술적 신호·수급·이슈는 계산하지 않는다(실측 수 ms, 카드 6개 동시 7.7~10.1초). 조건 추가·수정·삭제, 추적 켜고 끄기, 종목 빼기·되돌리기 뒤에 화면이 다시 읽는다.

| 영역 | 내용 | 원천 |

| 머리 | 현재가·전일 대비(장중이면 네이버 실시간, 아니면 종가)·시세 시각. 미국은 마지막 종가 | `portfolio_quotes`·`stock_prices` / `us_prices` |
| 차트 | 최근 120거래일 종가와 20·60·120일선, 원칙 조건의 가격선(손절·돌파) | `stock_prices` |
| 기술적 신호 | 52주 고점 대비·이평선 이격·거래량(20일 평균 대비)·상대강도·매물대 위·아래 물량·최근 5거래일 새 신호(기업 화면 '주요 신호'와 같은 기준)·시장 국면 | `technical_scan`·`investor_lens._gather_trend` |
| 수급 | 외국인·기관·개인 5일·20일 순매수(주식 수 × 종가 ≈ 금액)·외국인 보유율 변화 | `investor_flows` |

## 원칙 조건 (`tracker_conditions`)
진입·손절 조건을 미리 적어 두고(추세 원칙 4: 손절 라인은 진입 전에 정한다), 매일 상태를 판정한다.

| 유형 | 예 | 판정 |
|---|---|---|
| `price_below`(손절선) | 10,780원 아래 | 현재가 ≤ 기준가면 충족(경보) |
| `price_above`(돌파) | 14,470원 위 | 현재가 ≥ 기준가면 충족 |
| `close_below_ma` | 60일선 아래 마감 | 종가 < N일선 |
| `close_above_ma` | 120일선 위 마감 | 종가 > N일선 |
| `manual`(확인 항목) | 3분기 반도체 부문 매출 증가 확인 | 사람이 '확인함'으로 바꾼다 |

- 조건마다 역할(`entry` 진입·`exit` 손절·청산·`check` 확인)과 메모를 둔다.
- 충족으로 바뀌는 순간 알림을 보낸다. 같은 조건·같은 날은 한 번만 보낸다.

## 알림 (텔레그램, `portfolio_alerts.run`에 편승)
- **장중(30분)**: 전일 대비 ±5%p 구간 진입, 가격 조건(`price_*`) 충족, 오늘 공시
- **장 마감**: 오늘 새 기술적 신호, 이평선 조건(`close_*_ma`) 충족, 오늘 공시
- 미국 티커는 장 마감 점검에서만(위 '미국 티커 추적').
- 중복 방지 키는 포트폴리오 알림과 공유한다(`portfolio_alerts_sent`). 보유 종목과 추적 종목이 겹쳐도 같은 공시·신호가 두 번 오지 않는다. 문구는 '추적' 표시로 구분한다.
- 가격·비율만 싣는다(D-212).

## 화면 — 홈 › 내 종목 (`/home/stocks`, 2026-11-05 개편 3d, ia-redesign §4.4·§4.20·§4.28)
`components/home/HomeStocksPage` + 규칙 `lib/myStocks`. 기본 관심 묶음(`GET /groups/default-watch`) 하나를 본다.
- **머리 줄**(이 줄만 옅은 하늘색): 관심 n종목 · 추적 n(충족 n — 충족 요약 `/tracker/status`의 충족 조건 수, 요약이 오기 전엔 괄호 없이) · 상승 n · 하락 n · 오늘 켜진 감시 신호 n개(모바일은 생략). 보기 전환 `전체 · 추적 · 보유`(URL `?view=tracked|held`), '+ 종목 추가'(통합 검색 `/api/spine/search`의 국내 종목·미국 티커, 검색에 없는 티커도 '티커로 추가' — 서버가 자료 없는 티커는 404).
- **특징주**(전체 보기만): 오늘 신호가 들어온 관심 종목 4장(모바일 가로 스크롤 8장). 순서 = 신고가 신호(`high_*`) 먼저, 그다음 거래량 증가율(`volume_*` 값) 큰 순. 카드 = 이름·시장·신호 날짜·현재가·등락·신호 이름·근거 한 줄('거래량 전일 대비 +x%' / '고가 … — 직전 고점 … 돌파'). '신호 n개 모두 보기 ›'는 종목 묶음 화면. 신호 0이면 '오늘 들어온 신호 없음' 한 줄.
- **조건 충족 알림 줄**: 충족 요약(`/tracker/status`) 조건 중 `newly_met`이 있을 때만 한 줄(여럿이면 '외 n건'). 무거운 추적 카드(`/tracker/{code}`)는 펼친 행·조건 편집 시트에서만 부른다(D-301 — 카드 6~7개를 기다리면 7~10초 늦게 떴다). 누르면 그 행이 펼쳐진다(URL `?open=코드`).
- **목록**: 정렬 = 추적 중 → 신호 켜진 종목 → 등락 폭(절댓값). 추적 행은 모두, 비추적은 데스크톱 10개·모바일 6개 + 'n종목 더 보기'(D-301). 행 = 이름·시장(미국은 '미국' 배지)·현재가(국내 원·미국 달러)·등락(상승 빨강·하락 파랑)·오늘 신호·추적 스위치(shadcn Switch)·빼기(×, 데스크톱). 추적 행 이름(›)을 누르면 한 번에 한 행만 아래로 펼쳐져 원칙 조건 상태·기술적 신호·5일 외국인·기관 수급(미국은 '미국 종가 기준 · 52주 고점 대비')과 '조건 편집 · 종목 페이지 ›'가 보인다. '조건 편집'은 오른쪽 시트에 전체 추적 카드(차트·조건 추가·확인·삭제·수급·이슈).
- **미국 행 실적 배지**: 시즌 자료(`/transcript/season`)에서 곧 발표면 '실적 D-n', 지났으면 '실적 MM/DD · ±x%p ›'(첫 거래일 업종 대비) → 콜 상세. 팔로우 밖 티커는 배지 없음.
- **빼기**: 논지·목표가·종목별 감시 조건이 있으면 확인 창(AlertDialog), 없으면 바로 빼고 '되돌리기' 알림(다시 넣고 추적 표시 복구).
- **보유 보기**: 관심 종목 중 보유 종목 행 + 포트폴리오 오늘 · 다가오는 일정 · 보유 종목 자료 흐름 섹션. 전체 보기 아래에는 관심 종목 오늘 요약 섹션(이행 화면에서 옮긴 것).
- **5-state**: Empty = 관심 0이면 특징주·알림 줄·목록을 숨기고 '+ 종목 추가'만 · Loading = 머리 + 표 모양 스켈레톤(펼친 행은 그 칸만) · Partial = 신호 0이면 한 줄, 시세가 없는 행은 '-' · Error = 묶음 API 실패 시 BlockError + 다시 시도(펼친 행 카드 실패는 그 칸만) · Ideal = 위 전체.

## 위젯 틀 확장 (옛 홈 위젯 — 7단계 정리 대상)
- `WidgetDef.multi`: 같은 위젯을 여러 개 놓을 수 있다(종목마다 하나).
- `WidgetDef.pickParams`: 추가할 때 설정을 고르는 단계(종목 검색). 고른 값은 배치 항목의 `params`로 저장된다(기존 저장 형식 그대로).
- `WidgetDef.titleOf(params)`·`useMeta(params)`: 머리 제목·기준 시각을 위젯마다 다르게(종목명).

## 5-state (추적 카드 — 시트·옛 위젯)
| 상태 | 표시 |
|---|---|
| Empty | 종목을 고르지 않은 위젯 → 종목 검색 안내 |
| Loading | 카드 Skeleton |
| Partial | 수급·이슈 등 영역별로 자료가 없으면 그 영역에만 '자료 없음'과 이유(예: 수급은 다음 수집 때 채워짐, 미국 종목은 '투자자별 수급 자료가 없어요') |
| Error | ErrorState + 다시 시도 |
| Ideal | 위 표 전체 |

크기가 작으면(높이 3 이하) 머리 + 원칙 조건 상태 + 오늘 새 신호 한 줄만 보인다.
