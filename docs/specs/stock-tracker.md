# 종목 추적 위젯 (2026-10-20)

관심 묶음보다 한 단계 더 집중하는 추적이다. 홈 위젯을 **종목마다 하나씩** 놓는다. 위젯 하나는 그 종목의 차트·기술적 신호, 수급, 이슈, 내 원칙 조건을 한 카드로 보인다. 조건이 충족되면 텔레그램으로도 알린다.

## 추적 대상의 단일 원천
- 홈 메뉴들(`home_boards`, [home-widgets §5](home-widgets.md))에 놓인 `track.stock` 위젯의 `params.code`가 추적 종목이다. 어느 메뉴에서든 위젯을 모두 빼면 추적과 알림도 멈춘다.
- 별도 목록을 두지 않는다. 위젯과 알림 대상이 어긋나지 않게 하기 위해서다.
- 추적 종목은 수급 수집 대상(`flows.collect_flows`)에 관심 묶음과 함께 들어간다.

## 카드 구성 (`GET /api/spine/tracker/{code}`, LLM 0)
| 영역 | 내용 | 원천 |
|---|---|---|
| 머리 | 현재가·전일 대비(장중이면 네이버 실시간, 아니면 종가)·시세 시각 | `portfolio_quotes`·`stock_prices` |
| 차트 | 최근 120거래일 종가와 20·60·120일선, 원칙 조건의 가격선(손절·돌파) | `stock_prices` |
| 기술적 신호 | 52주 고점 대비·이평선 이격·거래량(20일 평균 대비)·상대강도·매물대 위·아래 물량·최근 5거래일 새 신호(기업 화면 '주요 신호'와 같은 기준)·시장 국면 | `technical_scan`·`investor_lens._gather_trend` |
| 수급 | 외국인·기관·개인 5일·20일 순매수(주식 수 × 종가 ≈ 금액)·외국인 보유율 변화 | `investor_flows` |
| 이슈 | 최근 14일 공시(대량보유·임원 지분·잠정실적 강조)·최근 7일 피드 문서 수와 최신 제목·증권사 목표주가 언급 | `disclosures`·`raw_documents`(entity_links·제목) |
| 내 원칙 조건 | 종목별 조건과 현재 상태(충족·미충족·확인 대기) | `tracker_conditions` |

## 원칙 조건 (`tracker_conditions`)
진입·손절 조건을 미리 적어 두고(추세 원칙 4: 손절 라인은 진입 전에 정한다), 매일 상태를 판정한다.

| 유형 | 예 | 판정 |
|---|---|---|
| `price_below`(손절선) | 10,780원 아래 | 현재가 ≤ 기준가면 충족(경보) |
| `price_above`(돌파) | 14,470원 위 | 현재가 ≥ 기준가면 충족 |
| `close_below_ma` | 60일선 아래 마감 | 종가 < N일선 |
| `close_above_ma` | 120일선 위 마감 | 종가 > N일선 |
| `manual`(확인 항목) | 3분기 반도체 부문 매출 증가 확인 | 사람이 '확인함'으로 바꾼다 |

- 조건마다 역할(`entry` 진입·`exit` 손절·청산·`check` 확인)과 메모를 둔다.
- 충족으로 바뀌는 순간 알림을 보낸다. 같은 조건·같은 날은 한 번만 보낸다.

## 알림 (텔레그램, `portfolio_alerts.run`에 편승)
- **장중(30분)**: 전일 대비 ±5%p 구간 진입, 가격 조건(`price_*`) 충족, 오늘 공시
- **장 마감**: 오늘 새 기술적 신호, 이평선 조건(`close_*_ma`) 충족, 오늘 공시
- 중복 방지 키는 포트폴리오 알림과 공유한다(`portfolio_alerts_sent`). 보유 종목과 추적 종목이 겹쳐도 같은 공시·신호가 두 번 오지 않는다. 문구는 '추적' 표시로 구분한다.
- 가격·비율만 싣는다(D-212).

## 위젯 틀 확장
- `WidgetDef.multi`: 같은 위젯을 여러 개 놓을 수 있다(종목마다 하나).
- `WidgetDef.pickParams`: 추가할 때 설정을 고르는 단계(종목 검색). 고른 값은 배치 항목의 `params`로 저장된다(기존 저장 형식 그대로).
- `WidgetDef.titleOf(params)`·`useMeta(params)`: 머리 제목·기준 시각을 위젯마다 다르게(종목명).

## 5-state
| 상태 | 표시 |
|---|---|
| Empty | 종목을 고르지 않은 위젯 → 종목 검색 안내 |
| Loading | 카드 Skeleton |
| Partial | 수급·이슈 등 영역별로 자료가 없으면 그 영역에만 '자료 없음'과 이유(예: 수급은 다음 수집 때 채워짐) |
| Error | ErrorState + 다시 시도 |
| Ideal | 위 표 전체 |

크기가 작으면(높이 3 이하) 머리 + 원칙 조건 상태 + 오늘 새 신호 한 줄만 보인다.
