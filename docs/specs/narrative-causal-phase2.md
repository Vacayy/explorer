## 1. 목표

Phase 1은 인과를 그래프에 *쌓기*만 했다. Phase 2는 그 그래프를 **읽어 가치로**:
① 인과 양 끝 순회 ② 메르식 서사 ③ 버전 드리프트 ④ 내러티브 머지·교차검증 ⑤ 내러티브↔지식 루프.

전제 게이트: 인과 엣지가 어느 정도(예: 5+ 주제 재생성) 쌓인 뒤 착수 — 순회·머지·교차검증은 데이터가 있어야 검증된다.

## 2. 능력별 설계

### 2-1. 인과 양 끝 순회 (traversal)
그래프를 거슬러/따라가 "가장 큰 원인"과 "최종 수혜"를 뽑는다.

- **앞의 끝(근본 원인)**: 한 노드에서 `CAUSES` 엣지를 **상류로** BFS. **정지 규칙 = 위상적 소스**(들어오는 CAUSES 엣지가 없는 노드) — layer 컬럼 없이 그래프 구조만으로. type 휴리스틱으로 우선순위(policy·macro·event·regime성 노드를 루트로 선호). 사이클은 Phase 1이 DAG(시간)로 막았으므로 무한루프 없음(방문 집합으로 이중 방어).
- **뒤의 끝(수혜)**: `CAUSES`/`BENEFITS_FROM`을 **하류로** → 종착 = **sector 노드**(종목 금지, Phase 1 결정). 여러 수혜 섹터는 경로상 confidence 곱으로 랭킹.
- **경로 구성**: 루트 → … → 수혜 섹터의 시간순(orientation) 경로. 한 노드가 여러 루트/수혜로 갈라지면 top-K 경로.
- 노드 layer가 필요해지면(정밀 정지 규칙) `entities.meta_json`에 pace_layer 저장 — Phase 1 프롬프트가 이미 layer를 뽑으므로 적재만 추가(후속 소분).

### 2-2. 메르식 서사
순회 경로를 **앞에서 뒤로 걸으며 잇고, 끝은 투자 함의(수혜 섹터)**로 닫는 서사.

- 현재 생성이 md+graph를 함께 뽑음(Phase 1). Phase 2는 **서사를 그래프 경로에 정박** — opus에 순회 경로(루트→수혜)를 입력으로 주고 "이 체인을 메르처럼 풀어써라"로 생성. 근거가 그래프라 각 문장이 어느 엣지에서 왔는지 역추적 가능.
- 표면: 내러티브 페이지에 "서사(현행)"와 "인과 흐름(메르 모드)" — 후자는 루트→수혜를 단락으로 걸어가며 각 hop의 mechanism·시간을 녹임.

### 2-3. 버전 드리프트
`/versions`(Phase 1)에 **버전 간 diff**를 얹는다.

- v(n-1)↔v(n) 서브그래프 비교: 추가/삭제된 노드·엣지, **핵심 고리 이동**("유가→금리가 빠지고 반도체→AI가 들어옴").
- 계량(LLM 0): 엣지 집합 차집합 + 노드 등장/퇴장. 요약 1줄은 게으른 haiku(선택).
- 표면: 내러티브 페이지 상단 "지난 버전 대비 달라진 것" 배지/토글, /versions 목록에 diff 미리보기.

### 2-4. 내러티브 머지·교차검증
같은 노드를 지나는 내러티브들은 이미 한 그래프의 서브그래프 — 이를 드러낸다.

- **머지(세계관 뷰)**: 공유 노드로 연결된 내러티브 집합 → 합집합 서브그래프 = "상위 세계관 내러티브". 노드 공유도로 클러스터(1차는 단순 공유 카운트, emergent 루트 클러스터는 후속).
- **교차검증**: 한 인과 엣지를 **2+ 독립 내러티브**가 주장하면 confidence↑(Phase 1의 재적재 confidence 강화가 씨앗 — narrative_id 다양성으로 독립성 판정). 상충(A→B vs 반대 방향/부정)은 `contested` 표시.
- 표면: 내러티브 페이지 "이 인과를 공유하는 다른 내러티브 N개" + 세계관 뷰(공유 서브그래프 시각화 — 노드-링크 or 계층 목록).

### 2-5. 내러티브 ↔ 지식 루프 (핵심)
빠른 층(내러티브)과 느린 층(지식)이 서로를 먹인다 — CLS 루프 완성.

- **내러티브 → 지식(승격)**: 인과 엣지가 **2+ 독립 내러티브에서 반복 + 시간 분산**되면 consolidation이 서술형 statement로 승격(knowledge). "A가 B로 이어진다"가 굳은 전제가 됨. 기존 승격 배치(독립 관측·간격 요건) 재사용, 입력을 인과 엣지로 확장.
- **지식 → 내러티브(주입)**: 생성 시 관련 corroborated 지식을 검증된 전제로 주입(knowledge_block 배선 기존, 인과 관련 지식 우선 소환). 지식의 **falsifier를 내러티브의 관전 포인트/반증 조건**으로, **contested 지식은 내러티브 불확실성**으로 표시.
- **루프**: 내러티브가 인과 제안 → 반복분 지식 승격 → 지식이 다음 내러티브 지지 → falsifier 감시 → 반증 시 지식 흔들림 → 내러티브 재생성.
- 표면: 내러티브 인과 엣지에 "승격된 지식" 배지(굳은 고리), 내러티브 하단 "이 서사가 딛고 선 지식 N건" + "흔들릴 조건(반증)".

## 3. 백엔드 변경 (개요)
- `pipeline/narrative_graph.py`(신규) — 순회(roots·beneficiaries·paths), 드리프트 diff, 머지(공유 서브그래프), 교차검증(엣지 독립 내러티브 카운트).
- `pipeline/narrative.py` — 메르 서사 생성 모드(경로 정박 프롬프트), 지식 주입 강화.
- `pipeline/consolidation.py` — 승격 입력에 인과 엣지 추가(내러티브→지식).
- API: `/narrative/{id}/chain`(루트→수혜 경로), `/narrative/{id}/diff`(직전 버전 대비), `/narrative/{id}/related`(공유 내러티브), `/causal/worldview`(머지 뷰).

## 4. 화면 (UX)
- **내러티브 페이지 확장**: 인과 구조 뷰 → 루트→수혜 **경로 강조**(접기/펼치기), 메르 모드 토글, 상단 드리프트 배지, "공유 내러티브"·"딛고 선 지식" 섹션, 승격 엣지·contested 표시.
- **세계관 뷰(신규, /causal/worldview 또는 지식 페이지 연계)**: 공유 노드로 엮인 내러티브 군집 — 노드-링크 최소 시각화 또는 계층 목록.

### 5-state
| 상태 | 처리 |
|---|---|
| Empty | 엣지 부족(순회 불가): 순회/머지 섹션 숨김 + "인과가 더 쌓이면 나타납니다" |
| Loading | 경로·diff·관련 각각 스켈레톤 |
| Partial | 본문·인과뷰(Phase 1) 먼저, 순회·머지·지식 섹션 뒤따름 |
| Error | 확장 섹션만 조용히 생략, 본문·기본 인과뷰 유지 |
| Ideal | 루트→수혜 경로 + 메르 서사 + 드리프트 + 공유 내러티브 + 딛고 선 지식 |

## 5. 구현 순서
1. 순회(roots·beneficiaries·paths) + `/chain` API + 페이지 경로 강조 → 2. 메르 서사 모드 → 3. 버전 드리프트 diff → 4. 머지·교차검증(공유/세계관) → 5. 지식 루프(승격·주입 강화). 각 단계 검증(tsc·API·5-state) 후 SYSTEM.md·DECISIONS 갱신.

## 6. Out of Scope
- 종목까지 하강(수혜 섹터→종목) — 별도 후속(종목 노드·리서치 성숙 후).
- 노드-링크 풀 인터랙티브 그래프 시각화(줌·드래그) — 1차는 계층 목록/최소 뷰.
- 루트 원인 emergent 클러스터 자동 카테고리 — 도메인 렌즈 유지, 후속.
- 자율 에이전트(질문 생성·능동 리서치) — 진화계획 3단계 별건.
