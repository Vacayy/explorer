# 화면 기획서: 스크리너

> 경로: `/discover/screener`
> 상태: 기획 완료, 구현 대기

---

## 1. 목적

재무 지표 조건을 설정하여 **투자 아이디어를 체계적으로 발굴**한다.
"PER 15배 이하, 영업이익률 20% 이상인 반도체 장비주"와 같은 조건 검색을 지원.

### v1 범위
- 대상: 재무 데이터가 이미 수집된 종목 (산업군 등록 + 유저 조회 이력 종목)
- 향후: 전 상장사 배치 ETL 완료 후 ~4,000 종목으로 확대

---

## 2. User Flow

```
스크리너 진입
  → 필터 조건 설정 (PER, OPM, ROE 등)
  → 조건 변경 → 0.5s debounce → 자동 재조회
  → 결과 테이블 스캔 (히트맵 색상으로 빠른 비교)
  → 관심 종목 클릭 → /analyze/:stockCode/summary 이동
  → 또는 "워치리스트에 추가" 버튼
```

## 4. 필터 패널 상세

| 필터 항목 | 입력 타입 | 기본값 | 범위 | 비고 |
|----------|----------|-------|------|------|
| PER | Max 입력 | 빈값 (전체) | 0 ~ 200 | 빈값 = 필터 안 함 |
| PBR | Max 입력 | 빈값 | 0 ~ 50 | |
| 영업이익률 | Min 입력 | 빈값 | -100% ~ 100% | |
| ROE | Min 입력 | 빈값 | -100% ~ 200% | |
| 매출성장률(YoY) | Min 입력 | 빈값 | -100% ~ 500% | |
| 시가총액 | 프리셋 선택 | 전체 | 소형(<3천억) / 중형(3천억~2조) / 대형(>2조) / 전체 | |

### 필터 동작 정책
- 필터 변경 시: **0.5초 debounce** 후 자동 재조회 (별도 "검색" 버튼 없음)
- 여러 필터 동시 설정: **AND 조건** (모든 조건 동시 만족)
- "필터 초기화" 버튼: 모든 필터를 빈값으로 리셋
- 필터 상태: **URL 쿼리 파라미터로 저장** (`/discover/screener?per_max=15&opm_min=20`) → 북마크/공유 가능

## 5. 결과 테이블

### 컬럼 정의

| 컬럼 | 정렬 | 기본 정렬 | 포맷 | 히트맵 |
|------|------|---------|------|--------|
| 종목명 | ✓ | - | 볼드 텍스트, 클릭 → /analyze 이동 | ✗ |
| 종목코드 | ✗ | - | 6자리 모노스페이스 | ✗ |
| 시가총액 | ✓ | DESC | 억/조 단위 | ✗ |
| PER | ✓ | ASC | 소수점 1자리 + "배" | ✗ |
| PBR | ✓ | ASC | 소수점 2자리 + "배" | ✗ |
| 영업이익률 | ✓ | DESC | 소수점 1자리 + "%" | ✓ |
| 매출성장률 | ✓ | DESC | 부호 + 소수점 1자리 + "%" | ✓ |
| 영업이익성장률 | ✓ | DESC | 부호 + 소수점 1자리 + "%" | ✓ |
| ROE | ✓ | DESC | 소수점 1자리 + "%" | ✓ |
| 액션 | ✗ | - | "+ 워치" 버튼 | ✗ |

### 히트맵 색상 정책
산업군 스크리너와 동일한 `HeatNum` 컴포넌트 재사용:
- `> 30%`: emerald-100 배경
- `> 15%`: emerald-50 배경
- `> 0%`: emerald-50/50 배경
- `> -10%`: rose-50/50 배경
- `> -30%`: rose-50 배경
- `≤ -30%`: rose-100 배경

## 6. 상태별 정책

| 상태 | 화면 |
|------|------|
| **초기 (필터 미설정)** | 전체 종목 시가총액 내림차순 표시 |
| **빈 결과** | "조건에 맞는 종목이 없습니다" + "필터 조건을 완화해보세요" 텍스트 + 필터 초기화 버튼 |
| **로딩** | 테이블 스켈레톤 (5행) |
| **에러** | "데이터를 불러올 수 없습니다" + 재시도 버튼 |
| **결과 100건 초과** | 상위 100건만 표시 + "결과가 많습니다. 필터를 추가해보세요" 안내 |

## 7. 데이터 모델

### API Endpoint

```
GET /api/screener
  ?per_max=15
  &pbr_max=3.0
  &opm_min=20
  &roe_min=15
  &rev_growth_min=10
  &mcap_tier=mid     (small|mid|large|all)
  &sort=market_cap
  &sort_dir=desc
  &limit=100
```

### Response Shape
```json
{
  "items": [
    {
      "stock_code": "403870",
      "corp_name": "HPSP",
      "market_cap": 238800000000,
      "per": 7.9,
      "pbr": 3.16,
      "op_margin": 52.0,
      "revenue_growth": -4.9,
      "op_profit_growth": 12.3,
      "roe": 22.1,
      "latest_close": 29850
    }
  ],
  "total": 32,
  "filtered_from": 187
}
```

### 데이터 소스
- `financial_statements` 테이블 (IS, BS) — 최신 연도 + 전년도
- `stock_prices` 테이블 — 최신 종가 + 시가총액
- 자체 계산: PER, PBR, ROE, 영업이익률, 성장률

### 대상 범위 (v1)
- `financial_statements`에 데이터가 **1년 이상** 존재하는 종목만
- 즉, 산업군 등록 종목 + 유저가 한 번이라도 조회한 종목
- 결과에 "전체 N개 중 M개 종목의 데이터가 있습니다" 표시

## 8. 인터랙션 상세

### 필터 입력
- 숫자 입력 필드: 포커스 시 전체 선택 (빠른 수정)
- 빈값 입력 = 해당 필터 해제
- 음수 허용 (매출성장률, 영업이익률)

### 테이블
- 행 호버: 배경색 변경
- 행 클릭: `/analyze/:stockCode/summary` 이동
- "+ 워치" 버튼 클릭: 워치리스트에 즉시 추가 (conviction=3 기본값), 토스트 표시
- 컬럼 헤더 클릭: 정렬 토글 (ASC ↔ DESC), 현재 정렬 컬럼에 ▲▼ 표시

### URL 동기화
- 필터 변경 → URL 쿼리파라미터 업데이트 (`useSearchParams`)
- 페이지 새로고침 시 URL에서 필터 복원
- 브라우저 뒤로가기 → 이전 필터 상태 복원

## 9. 제한사항 (v1)

| 항목 | v1 | 향후 |
|------|------|------|
| 필터 프리셋 저장 | 미지원 | v2 ("고PER 저PBR 성장주" 같은 프리셋) |
| 복합 조건 (OR) | 미지원 (AND만) | v2 |
| 기간 선택 (어떤 연도 기준) | 최신 연도 고정 | v2 (연도 선택 드롭다운) |
| 전 상장사 대상 | 수집된 종목만 | 배치 ETL 후 확대 |
