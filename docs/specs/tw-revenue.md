# 대만 월매출

> 상태: 구현(2026-10-17). 대만 반도체·IT 하드웨어·해운 91개사의 월매출을 밸류체인 층별로 본다.

## 1. 범위

- 대상: `backend/pipeline/tw_universe.py`의 91개사, 10개 층(파운드리·메모리 / IC 설계 / 후공정·테스트 / 웨이퍼·장비·소재 / 기판·PCB·CCL / AI 서버·ODM / 서버 부품 / 네트워크·광통신 / PC·메모리·디스플레이 / 해운). 대상을 늘리거나 줄이려면 이 파일만 고친다.
- 미국 상장(실리콘모션·하이맥스)은 대만 월매출 공시 대상이 아니라 넣지 않는다.

## 2. 원천

대만 상장사는 매달 10일까지 전월 매출을 MOPS(公開資訊觀測站)에 공시해야 한다. 금액 단위는 천 TWD이고, 연결 기준이다(자회사가 없으면 개별).

| 용도 | 원천 | 형식 |
|---|---|---|
| 최신 월 | TWSE Open API `openapi.twse.com.tw/v1/opendata/t187ap05_L` (상장) · TPEx Open API `tpex.org.tw/openapi/v1/mopsfin_t187ap05_O` (장외) | JSON, 키 없음 |
| 과거 월 | MOPS `mopsov.twse.com.tw/nas/t21/{sii\|otc}/t21sc03_{민국년}_{월}_{0\|1}.html` | HTML(Big5). `0`=국내, `1`=외국(KY) 법인. 한 달에 4페이지 |

날짜는 민국 연도(115 = 2026)를 `YYYY-MM`으로 바꿔 저장한다. 회사가 단 증감 사유(備註)도 원문 그대로 저장하고, `-`는 빈 값으로 정규화한다.

## 3. 수집

- `scripts/collect_tw_revenue.py`: 기본은 최신 월(두 Open API)이다. 하나라도 실패하면 예외로 끝낸다(반쪽 저장 금지). 최신 월에 빠진 회사가 있으면 `partial`로 남긴다.
- `--backfill N`: 과거 N개월(이번 달 제외)을 받는다. 85개사 이상 있는 달은 건너뛰어 이어 받기가 된다. MOPS는 빠른 연속 요청을 막아 페이지 사이에 2초를 둔다.
- launchd `twrevenue`: 매일 11:00. 월매출은 회사마다 1~10일 사이에 따로 올라오므로 매일 최신 월을 덮어쓴다(멱등 upsert). 따라잡기(D-249) 대상이라 노트북이 꺼져 있던 날도 다음 순회에서 메운다.
- 기록: `job_runs('tw_revenue')`.

## 4. API

`GET /api/spine/tw/revenue?months=36` (LLM·네트워크 0): `as_of`(가장 최근 공시 월), `fetched_at`, `reported/total`(그 월을 공시한 회사 수), `layers`, `items[]`를 돌려준다. 각 item은 코드·이름·층·역할·시장, 최신 월·월매출·YoY·MoM·3개월 YoY, `lagging`(전체 최신 월보다 공시가 늦음), 증감 사유, `series[]`(ym·월매출·YoY)를 담는다.

3개월 YoY = 최근 3개월 월매출 합 ÷ 같은 3개월의 전년 동월 합 − 1. 월별 변동이 큰 회사의 추세를 본다.

## 5. 위젯 `explore.twRevenue` (탐색 › 대만)

| 상태 | 표시 |
|---|---|
| Loading | 위젯 공통 스켈레톤 |
| Error | '불러오지 못했어요' + 다시 시도 |
| Empty | "대만 월매출을 아직 받지 못했어요. 매일 11:00에 수집합니다." |
| Partial | 공시 전인 회사는 `N월분` 배지(지난달 값), 머리에 `공시 n/91사` |
| Ideal | 층 선택(URL `tw_layer`) · 행 = 이름·역할 · 24개월 막대 · 최신 월매출(억 TWD) · YoY · 3개월 YoY, 3개월 YoY 높은 순 |

- 머리 시각은 `YYYY-MM 공시`이다. 전전월에서 멈췄고 11일이 지났으면 주의 색으로 보인다.
- 회사를 누르면 상세 창(URL `tw=<코드>`)이 열린다. 월매출 막대와 YoY 선(36개월), 회사가 밝힌 증감 사유, 원천을 보여 준다.
- 금액 표기는 `utils/format.formatTwdEok`(천 TWD → 억, 1,000억 이상 정수)를 쓴다.
