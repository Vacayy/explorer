# 첫 커버리지 — 메모리반도체 v0.1

> 2026-09-09. 메모리반도체 선택은 사용자 확정. 아래 기업·분류·처리 범위는 위임받아 정한 설계 기본값.
> 상태: 커버리지 설계 + 수집 자료 읽기·대화 연결 구현, 추출·검토 원장은 보조. 운영 수집·백필·원본 DB·워치리스트는 변경하지 않았다.
> 상위: [기대 변화 관측 시스템](expectation-observatory-greenfield.md).
> 기업 사업·관계는 하단 공식 자료로 확인. 관찰 우선순위는 시장점유율 순위나 투자 추천이 아니다.

## 1. 범위와 질문

**DRAM과 NAND를 대상으로, 공급·수요·가격·이익의 경로에 대한 투자자 기대가 어떻게 수정되는지 관찰한다.**
HBM만으로 시작하지 않는다. HBM 집중 담론과 다른 메모리 제품의 기대 변화를 함께 비교할 수 있어야 한다.
NOR·SRAM·차세대 비휘발성 메모리는 초기 심층 범위 밖이며 관련 자료는 탐색에 보존한다.
수급·정책·금리·환율은 공통 맥락으로 연결하며 별도의 전시장 분석 사업으로 확대하지 않는다.

핵심 질문:
1. 성장 지속/재가속/둔화의 예상 경로와 시점이 바뀌었는가?
2. 제품 가격이 오르느냐보다, 예상 인상 폭·지속 기간·정점 시점이 바뀌었는가?
3. 공급 제약 또는 증설의 시점·강도에 대한 기대가 바뀌었는가?
4. 같은 관측을 수요 자신감/과잉투자 위험 등으로 다르게 읽기 시작했는가?
5. 산업 낙관은 유지하되 특정 기업의 인증·점유율·수익성 기대만 바뀌었는가?
6. 가격 움직임 전에 기대가 바뀌었는가, 움직임 뒤 해석이 따라왔는가?

## 2. 분류 축: 단일 기업 폴더가 아닌 다중 연결

기업은 제품군 하나에 독점 배치하지 않는다. `제품 × 용도 × 기업 역할 × 쟁점 × 기간`으로 연결한다.
DRAM과 NAND는 기술 제품 계층, SSD는 NAND 기반 완제품 계층이므로 중복 합산하지 않는다.

### 화면에서 보는 세 가지 제품 시장

| 화면 묶음 | 기술 계층/하위 범위 | 중점 기대 |
|---|---|---|
| HBM | DRAM/HBM, 세대·적층·공급사·고객별 | 인증, 공급 계약, 양산 시점, 출하, 수익성, 공급 확대 |
| 일반 DRAM | DRAM/non-HBM: 서버 DDR, PC DDR, 모바일 LPDDR, 그래픽 GDDR | 용도별 수요, 재고, 가격 협상, 제품 전환, 공급 배분 |
| NAND·SSD | NAND 다이/웨이퍼와 SSD·임베디드 제품 구분; 기업용/클라이언트/모바일 | 저장 수요, 가격, 가동·공급, 제품 믹스, 재고·마진 |

'일반 DRAM'은 UI 편의 명칭으로 HBM 외 DRAM을 뜻한다. 균질한 단일 상품 가격으로 취급하지 않는다.
HBM은 DRAM의 하위 제품이지만 투자자 발언 비교에서는 별도 관측 화면을 둔다.
데이터센터 DRAM 전체를 HBM으로 매핑하지 않는다. 세대는 고정 열이 아니라 확장 가능한 속성으로 둔다.

### 용도와 역할

용도: AI 가속기 / 일반 서버 / PC / 모바일 / 자동차·산업 / 불명.
역할: 메모리 생산 / 메모리 구매·설계 요구 / 최종 수요·투자 / 장비·공정·패키징 / 정책·시장 맥락.
한 기업은 여러 역할을 가질 수 있다. 고객 관계는 단순 역할 분류와 달리 문서 근거·유효 기간이 필요하다.

## 3. 기업별 기본 커버리지

### A. 지속 비교하는 핵심 5개 기업

| 기업 | 연결 제품 | 초기 관찰 범위 |
|---|---|---|
| 삼성전자 | HBM·일반 DRAM·NAND/SSD | 메모리 사업 발언·실적/가이던스·투자자 기대; 연결 실적과 메모리/DS 범위 구분 |
| SK하이닉스 | HBM·일반 DRAM·NAND/SSD | 메모리 제품별 기대; Solidigm은 별도 발언/제품 주체로 연결 |
| Micron | HBM·일반 DRAM·NAND/SSD | 제품별 기대와 공식 자료; 회계 분기와 달력 분기 구분 |
| Kioxia | NAND/SSD | NAND 수급·출하·가격·투자·수익성 기대 |
| Sandisk | NAND/SSD | NAND와 완제품/용도별 기대; 과거 Western Digital flash 자료의 승계 |

핵심 5개는 동일한 발언 이력 기능을 제공한다. 삼성/SK/Micron 비교를 첫 검증 대상으로 삼고,
Kioxia/Sandisk는 첫 릴리스 범위에 포함하되 NAND의 자료 확보 상태를 따로 표시한다.
기업 전체 사업을 모두 분석하지 않는다. 삼성 스마트폰·파운드리는 메모리 쟁점에 관련될 때만 인접 맥락으로 읽는다.

### B. 처음부터 등록하되 쟁점 중심으로 보는 경쟁·공급 관찰 대상

| 대상 | 관찰 목적 | 처리 경계 |
|---|---|---|
| CXMT | DRAM 제품·공급 확대 및 경쟁에 관한 기대 | 공식 제품 발표와 외부 생산량/수율 추정을 분리 |
| YMTC | NAND 공급·기술·경쟁에 관한 기대 | 공급량/원가/정책 영향 미확인 시 추정으로 표시 |
| Nanya | DRAM 투자·공급·제품 전환 관련 기대 | HBM과 다른 DRAM 제품의 변화를 보는 비교 대상 |
| Winbond | specialty DRAM 관련 제품·공급 변화 | NOR 사업 전체 분석으로 범위를 넓히지 않음 |

이 범위는 중요도가 낮다는 뜻이 아니다. 제품 발표/실적/관련 투자자 주장 등 새로운 근거가 생기면 비교한다.
공시·자료 빈도가 낮은 기업의 침묵을 공급 변화 없음으로 해석하지 않는다.
공급 충격에 관한 반복된 핵심 쟁점이 되면 상시 비교 범위로 승격한다.

### C. 수요·생산 제약의 연결 대상

아래는 연결 후보이며 특정 회사 간 납품 관계나 최신 제품 사양을 확정하는 목록은 아니다.

- 가속기·시스템 요구: NVIDIA, AMD. 제품 일정·메모리 탑재·공급 제약 관련 자료만.
- 투자·사용 수요: Microsoft, Amazon, Alphabet, Meta. CAPEX·운영 용량·투자 회수와 메모리 연결 쟁점만.
- PC·모바일·서버 고객: Apple, Dell, Lenovo 등. 재고·출하·메모리 조달 관련 발언이 있을 때.
- 생산·공정·패키징: TSMC, ASML, Applied Materials, Lam Research, 한미반도체 등.
  메모리 공급능력·공정 전환·패키징 제약에 직접 연결된 문서만 처리.

핵심과의 관련성 근거가 없는 일반 기업 뉴스·실적 전반은 심층 대상이 아니다.
국내 소재·부품·장비 전종목과 모든 AI 인프라 기업을 첫 릴리스에 편입하지 않는다.
관계 후보는 탐색을 돕지만, 실제 관계와 경제적 효과는 해당 자료로 별도 검증한다.

## 4. 그룹·브랜드·생산능력 집계 규칙

1. Solidigm은 발언자/제품 주체로 구분하되 SK하이닉스 그룹 관계를 보존한다.
   그룹 합산에서 같은 매출·생산량을 다시 더하지 않는다.
2. Kioxia와 Sandisk는 별도 기업으로 비교하고 공동 생산 관계를 별도로 기록한다.
   양사가 인용한 공동 설비·투자는 중복 증설로 합산하지 않는다.
3. Sandisk와 Western Digital은 현재 동일 기업 별칭으로 합치지 않는다.
   분리 전 flash 자료는 당시 기업·사업·기간을 보존해 연결한다.
4. SK하이닉스·삼성·Micron이 세 제품 화면에 동시에 나타나도 기업·발언·문서를 중복 생성하지 않는다.
5. 기업, 사업부, 증권, 거래소, 제품/브랜드를 분리한다. 가격 비교는 해당 증권에 연결한다.
6. 이 분류는 산업 전체의 완전한 공급 통계가 아니다. 다루지 않는 업체·미확인 자료 범위를 표시한다.

## 5. 공통 쟁점 6개와 관측 사전

| 쟁점 | 모을 관측/주장 | 비교 시 주의 |
|---|---|---|
| 수요의 경로 | bit 수요·탑재량·고객 출하·투자 예상 | CAPEX 금액을 메모리 구매량으로 바로 환산하지 않음 |
| 공급의 경로 | wafer 투입·bit 공급·수율·가동·공정/제품 전환·증설 일정 | CAPEX, 장비 반입, 양산, 유효 bit 출하를 구분 |
| 가격의 경로 | ASP·계약/현물 가격·협상 전망·인상 폭·지속 기간 | 제품·용량·세대·용도·가격 종류·단위를 고정해 비교 |
| 경쟁/제품 지위 | 인증·샘플·양산·수주·점유율 주장 | 단계와 주장 주체를 분리; 인증 소문을 출하 사실로 바꾸지 않음 |
| 이익 전환 | 원가·믹스·마진·현금흐름·재고 | ASP 상승 중 믹스 효과와 같은 제품 가격 상승을 구분 |
| 해석/거래 태도 | 우려 사유·확신·가격 부담·행동 언급 | 산업 전망과 종목 가격 판단, 표현된 행동과 실제 거래 분리 |

모든 쟁점에서 수준/변화율/가속도/예상 시점/조건 변경을 별도 축으로 관찰한다.
예: '다음 분기 계약가 +10% 예상 → +5% 예상'은 여전히 상승 기대지만 동일 기준일 때 기대 하향이다.
'내년에도 부족 → 이번 분기가 정점'은 전망 기간과 주장 내용을 확인한 뒤 지속 기간 수정 후보로 기록한다.
공급 확대, HBM 전환과 일반 DRAM 공급의 관계 등은 고정된 인과 법칙이 아니라 근거를 연결할 가설이다.

### 최소 지표 정의

`metric / product / generation / application / issuer / reporting_scope / period /
unit / price_basis / currency / actual_or_guidance / published_at / known_at / evidence_id`.

수치가 공시되지 않은 경우 null. 회사 전체 CAPEX를 메모리 CAPEX로 복제하지 않는다.
기업의 분기 ASP 증감과 제품 현물가격 일별 변화를 같은 시계열로 잇지 않는다.
메모리 매출 총액만 있는 기업에서 HBM 기여도·마진을 임의 역산하지 않는다.

## 6. 투자자 관찰 집단

기존 유튜브·블로그·텔레그램 자료에서 반복 발언자 후보를 먼저 찾아 선정한다.
2026-09-09 읽기 전용 감사로 분포와 일부 원문을 확인했다. 소스 후보와 실제 발언자는 다르므로
직접 글/발언, 전언, 재전파를 구분한 뒤 관찰 집단을 확정한다. 개인 후보 명단은 로컬 검토 결과에만 둔다.

균형 있게 보고 싶은 관점:
- 제품·기술/공급을 깊게 설명하는 관점.
- 수요·실적·밸류에이션을 연결하는 관점.
- 가격·포지셔닝·수급을 설명하는 관점.
- 기존 낙관·비관에 반대 근거를 제시하는 관점.

동일인이 여러 관점을 가질 수 있다. 라벨을 영구 성향으로 고정하지 않는다.
처음 5~10명은 비교 가능한 발언 이력 확보를 위한 운영 목표이지 필수 정원은 아니다.
채널 운영자, 출연자, 인용된 애널리스트, 회사 경영진을 구분하고 원문 화자를 우선한다.
기업 IR은 공식 사업 주장, 투자자 발언은 기대 관측으로 역할을 분리한다.

## 7. 가격·심리·수급의 범위

핵심 기업의 가격/거래량/이벤트 타임라인을 기본으로 두되 거래소·통화·휴장·시간대를 보존한다.
한국 장중 변화와 전일 미국장 또는 당일 미국장을 같은 시점으로 취급하지 않는다.
시장/섹터 대비 움직임은 비교 창과 벤치마크를 명시한다. 상대 수익률 자체를 원인으로 쓰지 않는다.

투자자별 매매·공매도·대차·옵션·ETF 자료는 확보 가능한 범위부터 별도 관측으로 연결한다.
기업/국가별 제공 범위·빈도가 다르면 동일한 '수급 점수'를 만들지 않는다.
공포·탐욕은 표현과 행동 언급으로 관찰하며 가격 하락만으로 공포 발언을 생성하지 않는다.
알고리즘 매매·파생 헤지에 의한 움직임은 자료/모델이 없으면 발언자의 해석 또는 미확인 가설로 남긴다.

## 8. 첫 화면과 산출물

상단: 메모리 전체 → HBM / 일반 DRAM / NAND·SSD. 기업은 교차 필터.
내용은 기존 상위 설계의 5-state를 준수하며, 세 제품의 기대를 하나의 낙관/비관 점수로 합치지 않는다.

카드 예시(가상):
> DRAM 가격 상승 전망은 유지되지만, 두 투자자가 다음 분기 인상 폭을 낮춰 잡았다.
> A: +10% → +5%, 동일 제품/기간. B: 숫자 없이 '상승세 둔화'로 변경.
> C는 기존 전망을 유지. 비교 가능한 발언자 3명; 나머지는 새 발언이 없거나 기간이 다름.
> 계기: A가 인용한 고객 재고 자료. 실제 재고 자료 확보 여부 표시.
> 원문 전후 비교 / 사업 관측 / 주가·수급 / 미확인 사항.

일일: 기대 수정·새 우려·반박·전파 중 원문으로 확인할 가치가 있는 변화만.

## 9. 진행 순서와 검증

### 현재 준비 상태 (2026-09-09)

**완료:** 현재 저장본의 어휘 기반 분포 감사, 8개 소스의 초기 검토 역할 분리,
원문 스냅샷·해시를 포함한 수동 검토 사례 8개 구성. 자동 기대 변화 검출기의 평가 결과는 아니다.

- DB 전체 16,389건, blog/telegram/youtube의 제품 키워드 후보 1,440건. 제품은 중복 태그.
- 후보 중 본문 300자 미만 150건, 빈 본문 1건. 짧은 글도 의미 있는 전망일 수 있다.
- 유튜브 509건 중 192건은 raw_content에 정리본 표시가 있다. 후보 중 26건도 이 상태.
  기존 `_digest_body`는 자막 본문 대신 정리본+원본 길이 안내를 반환한다. 이를 직접 발언 인용으로 쓰지 않는다.
- 채널 등록의 author 필드는 실제 문서/영상 화자로 사용할 수 없다. 여러 RSS 피드는 같은 도메인으로 묶일 수 있다.
- 첫 사례에는 표현된 포지션 변화, 경쟁 우려 추가, 가격 피크 예상 수정 언급,
  리포트 전언, 동일 인터뷰 재전파, 공통 외부 원천, 정리본 경계, 전망 기간 분리가 포함된다.

**재현:** `python3 scripts/audit_memory_coverage.py` (표준 라이브러리, DB mode=ro/query_only,
동일 읽기 스냅샷, 모델·네트워크 호출 없음). 제목+markdown/대체 raw_content의 명시 제품 어휘 검색으로
후보를 좁히며, 의미 기반 전체 recall·투자자 능력·실제 시장 주장 정확성을 평가하지 않는다.

**산출물 위치:** `logs/memory-coverage/latest.json`(재생성 가능 집계),
`review.md`(후보 역할·실측·수동 검토), `review-cases.json`(원문 스냅샷·해시·초기 판정 경계).
개인 소스·수집 본문을 포함하므로 기존 logs gitignore를 따른다. 실험 결과를 새 spec에 복제하지 않는다.

**근거 조회 API 구현:** 저장 텍스트의 원문/파생 상태와 검토 단서를 별도 실험 라우터로 제공한다.
실제 화자는 unresolved이며 자동으로 확정하지 않는다. [공통 설계 §8](expectation-observatory-greenfield.md)의 API 계약 참조.
**보조 검토 도구 구현:** 별도 UI에서 초안 추출/직접 입력 → 화자·관측 층위·제품·기간 검토 → 승인 → 보수적 과거 비교 → 판단 메모를 저장한다.
실자료 smoke에서 초기에 거래 태도 변화가 누락되어 추출 우선순위를 보완했다. 개선 후 해당 인용은 확보했지만
거래 태도/수급 해석의 층위 구분 등은 여전히 교정이 필요하다. 모든 실자료 결과는 미승인 초안이며 품질 통과로 간주하지 않는다.
표명한 현금 비중 확대 → 축소 사례는 동일 채널·자기소개·원문을 대조한 수동 초안 2개도 준비했다.
이는 current 투자 태도 비교이며 장기 사업 전망 반전/실제 체결을 의미하지 않는다. 사용자가 확인한 후 승인한다.
**사용자 동선 개선:** `/experiments/expectations`는 저장 요약/관련 발췌를 읽고 곧바로 기존 챗봇에 질문하는 화면이다.
같은 소스의 과거 자료를 자동으로 찾아 첨부하며 발언 승인 없이 비교를 요청한다. 검토 원장은 `/review` 보조 경로에 둔다.
첫 실자료 대화에서 두 영상의 현금 비중/태도 차이와 원문 인용을 확인했다. 전체 품질 검증은 아니다.
**다음 평가:** 실제 읽기·질문 흐름에서 자료 누락과 답변 유용성을 확인하며, 8개 사례를 채점하고 20~30개로 보강한다. 단순 소스별 감성 시계열을 먼저 만들지 않는다.

1. 기존 데이터의 기업×제품×발언자×시간 분포를 읽기 전용 점검.
2. 핵심 5개와 인접 대상의 별칭/관계, 실제 원문 화자와 타임코드 보존 상태 확인.
3. 자료가 있는 기간에서 20~30개 비교 사례를 구성. 과거 창은 실제 보존 범위로 결정.
4. 삼성/SK/Micron 발언 비교와 NAND 비교 사례를 모두 포함한 얇은 전체 흐름을 검증.
5. 2주 내외 일상 관찰에서 중요 변화 누락·오탐·원문 확인 시간을 측정한 뒤 확장.

필수 반례:
- HBM 낙관 유지 + 일반 DRAM 우려, 동일 작성자 안에서 공존.
- NAND 감산 기대와 DRAM 증설 기대를 같은 공급 전망으로 합치지 않음.
- 기업 HBM 인증 우려를 산업 전체 수요 둔화로 확대하지 않음.
- 삼성 연결/DS/메모리 범위, Micron 회계분기, 기업별 가이던스 기간 불일치.
- Kioxia/Sandisk 공동 투자, Solidigm 그룹 중복, 분리 전후 Western Digital 문서.
- 제품 믹스 ASP 상승과 동일 제품 가격 상승의 혼동.
- 반복 인용·수율 소문·자료 미공개·침묵·뒤늦게 수집한 과거 발언.
- 상승 전망 유지지만 예상 상승 폭 축소; 긍정적 사업 전망과 명시적 종목 비중 축소의 공존.
