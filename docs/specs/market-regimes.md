# 국면 이력 — 과거 시장 국면 지도와 버크셔 상대성과

상태: P0 구현(2026-10-26). 화면 `/regimes`(탐색 › 국면 이력), 홈 위젯 `explore.brk`. 근거 조사: [research/market-regimes.md](../research/market-regimes.md).

홈 › 국면·리스크([market-regime](market-regime.md))는 **오늘의 비중 포스처**다. 이 문서는 **과거 국면 지도**다 — 지난 수십 년을 규칙으로 구간을 나누고, 그 위에 매크로 계열과 개별 자산의 상대성과를 겹쳐 본다.

## 1. 원칙

- 국면 라벨은 규칙으로만 만든다(LLM 0). 같은 파라미터면 언제 다시 계산해도 같은 구간이 나온다. 통계 모형(HMM·GMM)은 재추정 때 과거 라벨이 바뀌므로 라벨로 쓰지 않는다.
- 층마다 판정 성격을 밝힌다. **사후**(구간 경계는 나중에야 안다)와 **실시간**(그때 알 수 있었다)을 구분하고, 사후 국면은 **확정일**(규칙이 처음 충족된 날)을 함께 저장해 보인다.
- 오버레이(금리·신용 등)는 국면을 판정하지 않는다. 사용자가 겹쳐 보는 재료다.

## 2. 층

| 층 | 규칙 | 원천 | 성격 |
|---|---|---|---|
| A 시장 국면 | Lunde–Timmermann 대칭 20/20: 강세 중 직전 저점 이후 최고 종가 대비 −20% → 그 최고점이 고점(peak). 약세 중 직전 고점 이후 최저 종가 대비 +20% → 그 최저점이 저점(trough). 강세 = 저점 다음날~고점, 약세 = 고점 다음날~저점. 마지막 전환 이후는 **잠정** | S&P500 `^GSPC` 일별 종가(1927~) | 사후 + 확정일 |
| A 주석: 조정 | 강세 구간 안에서 직전 최고 종가 대비 −10% 이상(−20% 미만) 하락한 구간. 시작=그 고점, 끝=고점 회복일(미회복이면 열림). −18% 이상은 **임계 근접** | 같음 | 사후 |
| A′ 실시간 추세 | 월말 종가 > 10개월 단순이평이면 상승추세, 아니면 하락추세(Faber 2007). 월말에만 바뀐다 | 같음(월말 리샘플) | 실시간 |
| B 경기 침체 | NBER 침체 월(`USREC`=1). 발표 지연 4~21개월(평균 7.8개월)을 툴팁에 고정 | FRED `USREC`(1854~) | 사후 |

파라미터 버전 `lt-20-20/v1`. 국면 시작·끝 날짜, 시작·끝 종가, 변화율, 기간(일), 확정일, 잠정 여부를 낸다. 저장 테이블 없이 `us_prices`에서 매번 계산한다(2.5만 행, 수 ms). 데이터 시작~첫 극점은 상태를 모르므로 국면에서 뺀다.

**검증(2026-10-26)**: 1946~2022 약세장 시작·끝·낙폭이 Yardeni 표와 일치한다. 다른 점은 둘 — 2000~02와 2007~09를 각각 둘로 나눈다(사이 +21%·+24% 반등이 강세 문턱을 넘음). 대칭 규칙의 성질이라 화면 약세장 표에 적는다. 임계 근접은 1990·1998·2002·2011·2018·2025가 잡힌다.

## 3. 버크셔 상대성과

- **BRK 가격**: `BRK-B`(1996-05~). 그 이전은 `BRK-A`(1980-03~)를 첫 공통일 비율로 BRK-B 단위로 이어 붙인다. 배당이 없어 가격 = 총수익.
- **벤치마크**: `sp500tr` S&P500 총수익 `^SP500TR`(1988~, 기본) · `sp500` 가격지수 `^GSPC`(배당 제외) · `nasdaq` 나스닥 종합 `^IXIC`(1971~, 배당 제외). 배당 제외 지수와 비교하면 BRK 쪽이 배당수익률만큼 유리하게 보인다 — 화면에 표시.
- **비교(누적%)**: 기간 시작일 = 0%로 두 계열의 누적 수익률.
- **스프레드**: 상대강도 = BRK ÷ 벤치마크, 기간 시작 = 100. 오르면 BRK 우세.
- **롤링 12개월 초과수익**(월말): BRK 12개월 수익률 − 벤치마크 12개월 수익률(%p). **베타 조정** = BRK 12M − β·벤치 12M, β = 직전 36개월 월간 수익률 회귀 기울기.
- **국면별 표**: 층 A의 각 국면 구간에서 BRK 수익률 − 벤치마크 수익률. 데이터 시작 전에 시작한 국면은 시작일을 잘라 싣고(`clipped_start`) 요약에서 뺀다. 표·요약은 기간 선택과 무관하게 전체 이력 기준. 국면은 벤치마크와 무관하게 항상 S&P500 기준. 강세·약세별 요약(국면 수, BRK 우세 수, 초과수익 중앙값). 겹치는 롤링 창은 빈도 통계에 쓰지 않는다.
- **표본 크기와 반대 사례를 화면에 쓴다**: 1980년 이후 약세장은 5~6번뿐이다. 저베타(β≈0.7)만으로 하락장 방어가 상당 부분 설명된다(Frazzini·Kabiller·Pedersen 2018). 1998.6~2000.2에는 지수 상승 중 BRK가 크게 빠졌다.

## 4. API (`routers/spine_regimes.py`, `models/regimes.py`, `pipeline/regimes.py`)

| 경로 | 내용 |
|---|---|
| `GET /api/spine/regimes` | `as_of`·`params`·`phases[]`·`corrections[]`·`trend[]`(실시간 추세 구간)·`recessions[]`·`series`(S&P500 주말 종가)·`current`(국면·고점 대비 낙폭·저점 대비 반등·추세) |
| `GET /api/spine/regimes/brk?bench=sp500tr\|sp500\|nasdaq&range=1y\|3y\|5y\|10y\|20y\|all` | `points[]`(날짜·BRK%·벤치%·상대강도; 5년 초과는 주말 표본) · `rolling[]`(월말 12M 초과·β·베타 조정) · `phases[]`(국면별 수익률) · `summary` · 기간 안 약세장·침체 구간 |
| `POST /api/spine/regimes/collect` | 시세(`BRK-B`·`BRK-A`·`^GSPC`·`^SP500TR`·`^IXIC`)와 `USREC` 수집. 처음엔 전 이력, 이후 최근 1개월 |

오버레이 계열은 새 API 없이 `GET /api/spine/risk?keys=us10y,us2y,curve,baa10y,aaa10y`(장기 이력)를 쓴다.

## 6. 화면

### 탐색 › 국면 이력 `/regimes`

1. 머리: 제목 · 지금 국면 한 줄(강세/약세·시작일·고점 대비 낙폭·실시간 추세) · 기준일.
2. **국면 지도**: S&P500 로그 차트 + 약세장 음영(잠정은 빗금 대신 옅게) + 침체 음영(다른 색) + 실시간 추세 띠. 기간 `regime_range`(10y·20y·50y·all, 기본 all). 범례에 층별 사후/실시간 배지.
3. **겹쳐 보기**: 오버레이 계열 선택(`regime_overlay`, 기본 curve) → 같은 기간·같은 음영으로 아래 차트.
4. **버크셔 vs 지수**: 벤치(`brk_bench`)·보기(`brk_view`=compare|spread)·기간(`brk_range`, 기본 all) → 위 차트 + 롤링 12M 초과수익(막대) + 베타 조정선, 국면 음영.
5. **국면 표**: 국면별 기간·S&P 변화·확정일(지연 일수)·BRK 초과수익·베타 조정 초과. 위에 강세/약세 요약과 표본·반대 사례 안내.

### 홈 위젯 `explore.brk`(탐색 › 국면 이력 묶음)

벤치·보기를 URL `brk_bench`·`brk_view`로 공유. 5년 창, 약세장 음영, 머리 숫자 = 최근 12M 초과수익. 전체 보기 → `/regimes`.
