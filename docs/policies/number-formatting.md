# 정책: 숫자 포맷팅

---

## 1. 금액 포맷 (한국 원화)

| 범위 | 포맷 | 예시 |
|------|------|------|
| ≥ 100조 | `{N}조` (정수) | 100조, 221조 |
| 10조 ~ 100조 | `{N.N}조` (소수 1자리) | 15.3조, 22.2조 |
| 1조 ~ 10조 | `{N.NN}조` (소수 2자리) | 1.03조, 8.56조 |
| 1,000억 ~ 1조 | `{N,NNN}억` (콤마) | 1,234억, 8,563억 |
| 100억 ~ 1,000억 | `{NNN}억` | 100억, 738억 |
| 10억 ~ 100억 | `{NN.N}억` (소수 1자리) | 10.5억, 73.8억 |
| 1억 ~ 10억 | `{N.N}억` | 1.5억, 9.2억 |
| 1만 ~ 1억 | `{N,NNN}만` | 5,000만, 12만 |
| < 1만 | 원 단위 콤마 | 9,500, 350 |

구현: `utils/format.ts` → `formatKrw()`

## 0. 공통 — 부호와 숫자 서체

- 음수 부호는 하이픈(-)이 아니라 **마이너스 기호 −(U+2212)**. 양수는 `+`, 표시 자릿수로 0이 되면 부호 없음. `utils/format.ts`의 부호 붙는 포맷터(`formatPercent`·`formatPp`·`formatSigma`·`formatBp`·`formatKrw`)가 처리한다.
- 숫자는 Geist Mono tabular(`tabular-nums` 또는 `font-mono`).
- 등락색(`--up`·`--down`)은 가격 방향에만 쓴다. 버튼·선택 상태·범례에는 쓰지 않는다.

## 2. 주가 포맷

| 항목 | 포맷 | 예시 |
|------|------|------|
| 현재가 | 콤마 + "원" | 29,850원, 2,297,000원 |
| 변동률 | 부호 + 소수 2자리 + "%" | +3.24%, −1.56% |
| 변동 색상 | 상승 = 브랜드 분홍(라이트 `--up` #D83995) / 오렌지(다크 `--up` #FC734D), 하락 = 파랑(`--down`), 0 = 회색 | 숫자 글자는 `text-up-ink`·`text-down-ink`, 막대·점·선은 `--up`·`--down` (D-320) |

## 3. 재무 비율 포맷

| 항목 | 포맷 | 예시 |
|------|------|------|
| PER | 소수 1자리 + "배" | 7.9배, 25.3배 |
| PBR | 소수 2자리 + "배" | 1.15배, 3.16배 |
| 이익률 (OPM, ROE 등) | 소수 1자리 + "%" | 26.3%, −5.2% |
| 성장률 (YoY) | 부호 + 소수 1자리 + "%" | +36.2%, −4.9% |
| 이익률 변동 | 부호 + 소수 1자리 + "%p" | +1.5%p, −3.2%p |

## 4. 차트 축 포맷

| 축 | 포맷 | 예시 |
|------|------|------|
| 금액 Y축 (원) | 억/조 자동 전환 | 500, 1,000, 1조 |
| 금액 Y축 (억 단위) | 콤마 정수 | 100, 1,000, 10,000 |
| 비율 Y축 | 정수 + "%" | 0%, 10%, 20% |
| 날짜 X축 (연도) | 2자리연 + ".MM" | 19.12, 24.03 |
| 날짜 X축 (일별) | 2자리연 + "-MM" | 24-01, 24-06 |

## 5. 테이블 내 YoY 표시

| 조건 | 표시 | 색상 |
|------|------|------|
| 양수 | ▲+{N.N}% | `text-up-ink` |
| 음수 | ▼{N.N}% | `text-down-ink` |
| 0 | 0.0% | muted-foreground |
| 데이터 없음 | - | muted-foreground |

## 6. 빈 값 표시

| 상황 | 표시 |
|------|------|
| 데이터 없음 (null) | `-` (하이픈) |
| 계산 불가 (0으로 나누기) | `-` |
| 아직 미수집 | `-` |
| 문자열 `"None"`, `"nan"` | `-` |
