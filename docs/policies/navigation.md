# 정책: 네비게이션

---

## 1. 모드 전환 규칙

| 액션 | 결과 |
|------|------|
| 기업 검색 → 선택 | `분석` 모드 자동 진입 → 요약 탭 |
| 산업군/스크리너에서 종목 클릭 | `분석` 모드 자동 진입 → 요약 탭 |
| 워치리스트에서 종목 클릭 | `분석` 모드 자동 진입 → 요약 탭 |
| "발굴" 모드 버튼 클릭 | 마지막으로 본 발굴 서브탭으로 이동 |
| "리서치노트" 모드 버튼 클릭 | 마지막으로 본 리서치 서브탭으로 이동 |
| "분석" 모드 버튼 클릭 (기업 있음) | 마지막으로 본 분석 서브탭으로 이동 |
| "분석" 모드 버튼 클릭 (기업 없음) | 비활성 (클릭 불가) |

## 2. URL 정책

| 규칙 | 설명 |
|------|------|
| 모든 화면은 고유 URL | 북마크, 브라우저 뒤로가기 완전 지원 |
| URL이 유일한 상태 소스 | useState가 아닌 URL에서 모드/탭/기업 결정 |
| 레거시 URL 리다이렉트 | `/company/:code/:tab` → `/analyze/:code/:tab` 자동 변환 |
| 스크리너 필터 URL 저장 | `/discover/screener?per_max=15&opm_min=20` |
| 없는 종목코드 접근 | "기업 정보를 찾을 수 없습니다" 에러 화면 |

## 3. 사이드바 정책

| 규칙 | 설명 |
|------|------|
| 항상 표시 | 모든 모드에서 우측 사이드바 접근 가능 |
| 접기/펼치기 | 사용자 토글. 접힌 상태는 세션 유지 |
| 사이드바 내용 | 워치리스트 (v2부터. v1은 기존 검색 히스토리 유지 후 전환) |
| 활성 종목 표시 | 현재 분석 중인 종목에 파란색 하이라이트 |

## 4. 브라우저 정책

| 규칙 | 설명 |
|------|------|
| 새 탭에서 열기 | 미지원 (SPA, 단일 탭 사용 전제) |
| 새로고침 | URL에서 상태 완전 복원 |
| 뒤로가기 | 이전 화면으로 정상 이동 |
| 앞으로가기 | 정상 동작 |
