    원문 작성자의 주장 · 가상

    “고객의 설비투자 재개를 주목한다”

    수집한 투자자 글에서 고객 투자를 기대하는 의견과, 실제 발주 시점을 확인해야 한다는 반론이 함께 발견되는 예시입니다.

    가상 투자자 글 · 09.12 / 반론 글 · 09.15
    동일 원문 재전파는 별도 의견으로 세지 않습니다.

    조사할 질문

    • 기대가 달라진 계기는 무엇인가?
    • 독립적인 원문에서 같은 변화가 보이는가?
    • 확인된 주문과 기대를 구분할 수 있는가?

    수집한 채널의 논의를 시장 전체의 합의나 실제 자금 유입으로 해석하지 않습니다.

    연결 가설 · 가상

    고객 투자 → 장비 발주 → A의 수주

    고객의 투자 계획은 조사 단서입니다. 해당 공정에 A의 장비가 쓰이는지, 공급 관계와 납기·매출 인식 시점이 맞는지 연결마다 확인합니다.

    가상 고객 투자 발표 · 09.05
    기업 A의 직접 공급 관계는 아직 미확인

    반대 가능성

    고객이 투자를 늘려도 다른 공정이나 경쟁사 장비에 집중할 수 있습니다. 공동언급과 실제 공급 관계를 구분합니다.

    다음 확인

    기업의 제품 설명, 고객 공시, 수주와 매출 인식 자료.

    자료에서 확인한 수치 · 가상

    매출 회복과 수익성 개선을 따로 확인

    가상 예시에서는 매출이 전년 동기보다 증가했지만 영업이익률은 낮아졌습니다. 제품 구성·비용·일회성 요인에 대한 설명이 필요합니다.

    비교의 기준

    연결/별도, 분기/누적, 회계기간과 단위를 맞춥니다. 실적 발표 시점과 귀속 분기를 따로 표시합니다.

    시장 예상치를 확보하지 못하면 “예상 상회”라고 쓰지 않습니다.

    경영진의 발언 · 가상

    “문의 증가”가 “발주 확정”으로 바뀌었나?

    직전 콜과 최근 콜의 발언을 함께 읽고, 수요·가동률·납기·가격·가이던스의 변화와 유지된 내용을 구분합니다.

    가상 콜 A · 05.15 / 가상 콜 B · 08.14
    경영진 답변과 질문자의 가정을 구분

    자료가 없을 때

    한국 기업의 콜 전문이 없다면 미확보로 표시하고, 확보된 IR 자료·공시의 설명을 출처 종류 그대로 제공합니다.

    수집일이나 회계분기 추정일을 실제 컨퍼런스콜 날짜로 사용하지 않습니다.

    관련 통계의 적용 가능성 검토 · 가상

    품목 수출의 증가가 이 기업과 연결되는가?

    HS 품목의 범위와 A의 제품이 일치하는지 확인합니다. 품목 총수출은 국가 전체의 통계이며, A의 매출이나 시장 점유율을 직접 보여주지 않습니다.

    통계 대상월 · 8월 / 공식 발표일 · 미확인
    품목 코드 및 실제 제품 연결 · 검토 필요

    확인할 차원

    • 금액 증가와 물량 증가의 구분
    • 계절성·기저효과·중량 단위
    • 상위/하위 HS 중복 여부
    • 관측월과 공개 시점의 차이
    확인된 사실 · 원문 주장 · 연결 가설 · 미확인을 구분합니다.

    최종 판단은 사용자 기록
    에이전트의 조사 제안 · 가상

    고객의 투자 계획이 기업 A의 수주 증가로 연결되는지 확인해 볼 만합니다. 직접 공급 관계와 실적 반영 시점은 추가 근거가 필요합니다.

    시스템 제안을 참고해 직접 기록합니다. 이 데모의 기록은 새로고침하면 초기화됩니다.

    사용자가 저장한 기록 · 예시

    이어서 확인할 항목

    후속 근거를 확인하면 새로 알려진 사실, 기존 가설에 미치는 영향, 다음 질문을 함께 보여줍니다.
    10.30 후속 자료 · 가상 예시

    기대는 유지되지만 실적 반영이 늦어질 수 있습니다.

    새 주장: 가상기업 A가 일부 납품 일정의 지연을 설명했습니다.

    판단에 미치는 영향: 고객 투자 확대 가설과 당장 매출이 늘어날 것이라는 가정을 나누어 검토해야 합니다.

    다음 질문: 취소와 지연 중 무엇이며, 수주잔고에는 어떤 변화가 있는가?

    기존 사용자 기록은 그대로 보존합니다.

    변화 중심으로 읽기 · 새 독립 근거, 반대 근거, 자료 지연을 구분합니다. 같은 기사의 반복 게시나 생성 요약을 새로운 증거로 세지 않습니다.
    네 단계는 위 탭으로 자유롭게 이동할 수 있습니다.

    03 / Search as an evolving tool

    검색을 대화로 발전시키고, 전략으로 축적합니다.

    도구의 계산 기준은 명확하게 유지하면서 질문·조건·대상 집합은 유연하게 바꿉니다.

    01

    자연어 + CodeAct

    질문을 계산 가능한 조건으로 해석하고, 필요한 데이터를 조회·분석합니다. 결과를 관찰한 뒤 후속 질문으로 탐색을 이어갑니다.

    조건식 확장: AND / OR / 제외 / 순위 / A 이후 B / 연속 유지. 현재 일반 카탈로그는 최대 12개 AND 조합입니다.

    02

    내 검색 라이브러리

    “무엇을 찾으려는가”와 조건을 함께 저장합니다. 같은 정의로 날짜를 바꿔 실행하고, 조건 변경은 새 버전으로 남깁니다.

    저장 항목: 목적·조건·매개변수·대상 집합·기준일 정책·필요 이력·도구 버전·검증 범위.

    03

    이유가 있는 추천

    관심 목적, 실행 가능한 자료, 선택 종목의 관측 신호에서 다음 검색을 제안합니다. 추천 이유와 조건을 먼저 보여줍니다.

    예시 전략부터 시작해 사용 경험으로 확장합니다. 개인화와 현재 시장 상황을 반영한 추천은 후속 단계입니다.

    조건의 의미를 보존

    0건이면 0건으로 남깁니다. 자료 부족을 알려주고 완화안을 제안하되, 원 질문의 기간·시장·조건을 임의 변경하지 않습니다.

    새 계산의 상태를 공개

    기존 도구 밖의 생성 계산은 실험 상태입니다. 저장 버튼을 눌렀다는 이유로 검증된 스킬이나 활성 코드가 되지 않습니다.

    활용 경험과 성과를 분리

    반복 사용, 후보의 중복, 리서치로 이어진 경험, 데이터 범위, 백테스트 결과를 각각 살펴봅니다.

    질문·이전 조건→계획·코드 작성→격리 계산→관찰·검증→결과·후속 탐색

    원본 데이터는 읽기 전용 입력으로 제공합니다. 계산기와 검증기, 입력 데이터의 버전을 실행에 고정합니다.

    04 / Research with a question

    발견한 움직임을, 사업과 기대의 변화에 연결합니다.

    시장 담론을 모으고, 실적과 경영진 설명을 읽고, 산업·통계로 대조합니다. 관련 있어 보이는 자료에서 실제 설명에 필요한 근거로 좁혀 갑니다.

    08 / Build the complete path, step by step

    작은 흐름을 끝까지 연결하고 넓힙니다.

    순서는 아래와 같습니다. 기간 추정이나 자동화 범위를 임의 확정하지 않고, 각 단계의 사용자 흐름과 검증 결과로 다음 단계를 결정합니다.

    00

    쓸 자료의 시점·단위·연결 검증

    연결 전 점검

    대표 기업·기간에서 공개 시점, 원문 확보 수준, HS 중복·결측, 기업 연결을 확인합니다. 검증된 자료부터 연결합니다.

    통과 기준 · 사실·추정·미확인이 구분되고, 사용할 자료의 근거와 공개 시점을 추적할 수 있음.
    우선 점검 사례
    • 미래로 추정된 콜 날짜와 파생 관측의 격리·정정 근거
    • 수출입 중복 합산, 누락값과 실제 0의 구분
    • 하나의 관측을 관련 없는 인과 주장 전체의 확증으로 확산하지 않음
    01

    검색 저장과 재실행

    현재 검증 가능한 조건을 이름·목적과 함께 저장하고, 실행 이력·기준일 정책을 연결합니다. 작은 예시 전략 묶음을 제공합니다.

    통과 기준 · 저장→재실행→이전 조건·결과 확인. 열람·새로고침이 새 계산을 시작하지 않음.
    02

    후속 질문과 동적인 조건 조합

    이전 질문·대상 집합·기준일을 이어받고, 필요한 OR·제외·사건 순서·연속 유지 표현을 계산·검증과 함께 추가합니다.

    통과 기준 · 대표 후속 질문의 변경분만 적용되고, 지원하지 않는 조건을 누락하거나 바꾸지 않음.
    03

    종목 발견에서 근거 조사까지

    “이 종목 조사”에 발견 맥락을 전달합니다. 기업 화면과 기존 검색·원문 읽기를 연결해 질문별 근거·반대 근거·공백을 남깁니다.

    통과 기준 · 검색 결과에서 관심 종목을 선택하고, 발견 이유를 유지한 채 실제 관련 원문을 확인할 수 있음.
    04

    사용자 판단과 후속 관찰

    관심 이유·확인할 사건을 저장하고, 실제 작동하는 관측 소스에 연결합니다. 새 근거와 기존 판단을 나란히 보여줍니다.

    통과 기준 · 실제 새 자료가 기존 가설에 연결되며 사용자 기록과 이전 버전을 보존함.
    05

    추천·역방향 탐색·산업 연결 확대

    사용 경험을 바탕으로 이유 있는 검색 추천을 확장합니다. 기업–고객–품목 관계와 원천 커버리지를 보강합니다.

    통과 기준 · 추천 이유·조건·필요 자료를 검토하고 선택 실행. 검증되지 않은 노출 관계를 확정하지 않음.

    상태보여줄 내용
    Empty · 시작 전/0건질문 예시와 시작 방법. 평가 후 0건은 실제 검사 범위와 함께 표시.
    Loading · 실행 중검색·계산·검증·원문 확인을 구분. 취소와 이미 확보한 결과 유지.
    Partial · 일부 확인확인한 내용부터 제공하고 미평가 조건·자료·연결의 이유 표시.
    Error · 실패0건과 실패를 구분. 입력·원문·사용자 기록을 유지한 재시도.
    Ideal · 조회 가능조건·시점·선별 이유·근거·사용자 기록·후속 질문이 연결된 상태.
