레이아웃은 하나, 상세의 역할은 둘

01 · 돌아갈 곳을 남긴다

‘뒤로’ 대신 ‘피드로 돌아가기’처럼 출발점을 설명합니다. 원래 채널, 필터, 페이지, 원문/요약 보기와 스크롤을 보존합니다.

새 탭·직접 URL 진입은 문서의 출처 또는 내러티브 목록으로 안전한 복귀 경로를 제공합니다.

02 · 읽는 표면을 통일한다

14px 본문, 24px 제목, 18/16px 소제목. 카드 안에 본문 카드를 다시 넣지 않습니다. 저장·대화·원문은 공통 상단 액션으로 정리합니다.

본문 폭 680–760px. 충분한 폭에서만 보조 맥락 220px, 좁으면 본문 아래로 이동. 팔로우 레일은 상세에서 기본 접힘 제안.

03 · 확인과 해석을 구분한다

문서는 수집된 원문을 우선합니다. 내러티브는 AI 해석임을 표시하고 근거와 버전으로 확인할 수 있게 합니다.

새로운 ‘기대 변화’ 요약이나 섹션을 저장 근거 없이 만들어 채우지 않습니다.

적용 순서

1. 문서 상세 + 복귀 상태 → 2. 내러티브 상세 + 근거·이력 정리 → 3. 출처·인물·기업 등 대상 상세

우선 전체 페이지 상세의 품질을 맞춥니다. 빠른 근거 확인용 오버레이는 그다음에 검토합니다. 같은 문서 본문 컴포넌트를 재사용하고, 오버레이 안에서 상세를 계속 중첩하지 않습니다.

확인할 계약: URL 새로고침/공유, 브라우저 뒤로가기, 복귀 시 스크롤과 포커스, 긴 제목·표·이미지, 모바일·다크, 로딩·빈 상태·오류. 내러티브의 기존 진입 시 자동 재생성 정책은 읽기 UI와 별개 결정이므로 이번 프로토타입에서 실행하지 않습니다.
