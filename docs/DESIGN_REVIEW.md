# Stock Explorer — Design Review

> 프론트엔드 디자인 리드 관점의 기획/디자인 리뷰
> 2026-06-15

---

## 총평

기획 문서 자체는 훌륭합니다. PRD의 문제 정의가 명확하고, 워크플로우 기반 3단계 IA가 타겟 유저의 실제 행동 패턴과 잘 맞습니다. 화면 기획서의 상태별 정책, 숫자 포맷팅 표준도 실무에서 바로 쓸 수 있는 수준입니다.

하지만 **현재 구현과 기획 사이에 간극**이 있고, **시각 디자인 레이어가 아직 정의되지 않았습니다.** 아래에서 구체적으로 짚겠습니다.

---

## 1. 지금 가장 큰 문제: 시각적 정체성이 없다

현재 CSS를 보면:

```css
--color-primary: #1d4ed8;        /* 기본 Tailwind blue-700 */
--color-background: #f9fafb;     /* gray-50 */
--color-chart-blue: #4472C4;     /* Excel 기본 파란색 */
--color-chart-orange: #ED7D31;   /* Excel 기본 주황색 */
```

이건 **Tailwind 기본 팔레트 + Excel 차트 색상**입니다. 금융 도구에 특화된 의도적 선택이 아니라, "색을 아직 안 골랐다"에 가깝습니다.

### 제안: 금융 도구를 위한 의도적 팔레트

금융 데이터 도구의 핵심은 **숫자의 가독성**입니다. Bloomberg Terminal이 검은 배경을 쓰는 이유는 스타일이 아니라, 밝은 텍스트가 숫자 밀도가 높은 화면에서 더 잘 읽히기 때문입니다. 하지만 이 서비스는 라이트 모드를 선택했고, 그러면 다른 전략이 필요합니다.

```
배경:    #FFFFFF (순백) — 회색 배경(#f9fafb)은 카드 경계를 약하게 만듦
표면:    #F8F9FC — 카드, 사이드바 (순백과 구분되는 아주 미세한 쿨그레이)
강조:    #1B2559 — 네이비 (trust, authority를 전달하는 금융권 표준)
액센트:  #2563EB — 블루 (링크, 활성 탭, CTA)
상승:    #DC2626 — 빨강 (한국 주식 컨벤션)
하락:    #2563EB — 파랑
히트맵+: #059669 → #D1FAE5 (emerald 그라데이션)
히트맵-: #DC2626 → #FEE2E2 (red 그라데이션)
```

핵심: **primary를 네이비(#1B2559)로, accent를 블루(#2563EB)로 분리**. 네이비는 헤더/모드 버튼 등 구조에, 블루는 인터랙티브 요소에. 현재는 둘 다 `#1d4ed8`이라 구조와 액션의 구분이 없습니다.

---

## 2. 타이포그래피: 숫자가 주인공인 서비스에 숫자 서체가 없다

현재:
```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, ...
```

시스템 폰트는 범용적이지만, **금융 데이터 도구에서 숫자의 가독성은 핵심 품질 지표**입니다.

### 제안

```
숫자/데이터:  "Tabular Lining" 지원 서체 — Inter 또는 IBM Plex Sans
본문:        Pretendard (한글) — 이미 한국 금융 서비스에서 표준
헤더/강조:   Pretendard Bold — 별도 디스플레이 서체 불필요 (데이터 도구는 절제가 미덕)
```

핵심: `font-variant-numeric: tabular-nums`를 테이블과 KPI 카드에 전역 적용. 현재 `tabular-nums` 클래스가 일부에만 적용되어 있는데, **모든 숫자 셀에 일관 적용**해야 테이블 컬럼이 정렬됩니다.

---

## 3. 네비게이션: 2단 구조가 시각적으로 무겁다

현재 ModeNavigation은 Level 1(모드 pill) + Level 2(서브탭)로 두 줄을 차지합니다. 헤더(검색바)까지 합치면 **상단에 3줄(~110px)을 소비**합니다. 데이터 도구에서 이건 과합니다.

### 제안: 1.5줄 네비게이션

```
┌──────────────────────────────────────────────────────────┐
│ SE  [검색...]        발굴 ∙ 분석:HPSP ∙ 리서치노트        │ ← 헤더와 모드를 한 줄에
├──────────────────────────────────────────────────────────┤
│ 산업군  스크리너  시그널  대안데이터                        │ ← 서브탭만 별도 줄
└──────────────────────────────────────────────────────────┘
```

로고를 축약(SE 또는 아이콘)하고, 검색바와 모드 pill을 **같은 줄 양쪽**에 배치하면 1줄 절약됩니다. 데이터 도구는 1픽셀이라도 더 콘텐츠에 써야 합니다.

---

## 4. KPI 카드: 6열 그리드가 좁다

현재 `grid-cols-6`로 6개 카드를 한 줄에 넣는데, 1440px 컨테이너에서 사이드바(220px)를 빼면 **카드당 ~180px**입니다. "2,297,000원" 같은 긴 숫자가 넘칠 수 있습니다.

### 제안

- 6개 KPI를 **3+3 또는 2행×3열**이 아닌, **한 줄 인라인 스트립**으로
- 카드 형태가 아닌, Bloomberg 스타일의 **수평 스트립**: `현재가 29,850원 ▲3.2% │ 시총 2,388억 │ PER 7.9 │ PBR 3.2 │ OPM 26.3% │ ROE 22.1%`
- 이렇게 하면 카드 간 여백을 없애고, 한 줄에서 스캔 가능. 전문 투자자는 카드 UI보다 **밀도 높은 한 줄 요약**을 선호합니다.

---

## 5. 차트 컬러: Excel 기본색에서 벗어나야 한다

`#4472C4`, `#ED7D31`은 Excel/PowerPoint의 기본 차트 색상입니다. 전문 투자자는 이걸 **매일** 봅니다. "이 서비스는 엑셀 위에 얹은 거구나"라는 인상을 줍니다.

### 제안: 의미 기반 차트 색상

```
매출액:     #3B82F6 (밝은 파랑) — 규모/크기를 나타내는 기본 색
영업이익:   #10B981 (에메랄드) — 이익은 초록 계열이 직관적
순이익:     #059669 (진한 에메랄드)
OPM 라인:  #6B7280 (gray-500) — 비율은 중립적 회색
상승 바:    #EF4444 (빨강) — 한국 컨벤션
하락 바:    #3B82F6 (파랑)
```

핵심: **색상에 의미를 부여**. "첫 번째 시리즈 = 파랑"이 아니라 "매출 = 파랑, 이익 = 초록"이 모든 화면에서 일관되게.

---

## 6. 기획서에 빠진 것들

### 6-1. 기업 간 전환 마찰

현재 기업 A를 분석하다가 기업 B로 전환하려면: 검색바 클릭 → 이름 입력 → 선택. **3스텝**입니다.

워치리스트 사이드바에서 클릭하면 1스텝이지만, 워치리스트에 없는 종목은? 산업군 테이블에서 옆 종목을 보려면?

**제안**: 분석 모드에서 기업명 옆에 **이전/다음 화살표** 또는 **산업군 내 동종기업 퀵 네비게이터** 추가. "HPSP를 보다가 옆에 있는 주성엔지니어링을 바로 보고 싶다"가 자연스러워야 합니다.

### 6-2. "분석" 모드의 요약 페이지가 너무 많은 역할

기획서에 따르면 요약 = Hero KPI + 분기 미니테이블 + 실적차트 + 시총차트 + 최근공시 + (P1에서) Metrics 차트 8개 통합. 이러면 **스크롤이 3~4 화면 분량**이 됩니다.

전문 투자자가 "요약"에서 기대하는 건: **스크롤 없이 한 화면에서 핵심 판단**. 나머지는 탭으로 분리하는 게 맞습니다. Metrics 통합은 재고 필요.

### 6-3. 스크리너와 산업군의 관계

스크리너는 전체 종목 대상, 산업군은 카테고리별 뷰. 하지만 유저 관점에서 "반도체 장비주 중에서 PER 15 이하"는 **산업군 + 스크리너의 교차**입니다. 두 기능이 분리되어 있으면 이걸 못 합니다.

**제안**: 산업군 테이블에 인라인 필터 추가. 또는 스크리너에 "산업군" 필터 옵션 추가. 둘 중 하나는 필요합니다.

### 6-4. 빈 상태의 톤

정책 문서의 빈 상태 메시지가 **설명적이지만 방향을 주지 않습니다**:
- "관심 종목을 추가해보세요" → 어떻게?
- "기업을 선택해주세요" → 어디서?

**제안**: 빈 상태에서 **구체적인 다음 행동을 직접 제공**. 빈 워치리스트라면 "반도체 밸류체인에서 탐색하기" 버튼을 넣는 것. 텍스트만으로는 부족합니다.

## 7. 구현 시 권장 사항

| 영역 | 현재 | 권장 |
|------|------|------|
| 배경색 | #f9fafb (회색) | #FFFFFF (순백) + 카드 #F8F9FC |
| Primary | #1d4ed8 (단일) | 네이비 #1B2559 (구조) + 블루 #2563EB (액션) |
| 숫자 서체 | 시스템 폰트 | Inter + Pretendard, `tabular-nums` 전역 |
| 헤더 높이 | ~110px (3줄) | ~80px (2줄) |
| KPI | 6열 카드 그리드 | 수평 인라인 스트립 |
| 차트 색상 | Excel 기본 | 의미 기반 (매출=파랑, 이익=초록) |
| 요약 페이지 | Metrics 8개 통합 예정 | 통합 재고, 스크롤 1화면 이내 유지 |

## 8. 결론

기획은 **전문 투자자의 워크플로우를 정확히 이해한, 잘 구조화된 문서**입니다. 이 기획을 살리려면 시각 디자인 레이어를 "Tailwind 기본값"에서 **"이 서비스만의 의도된 선택"**으로 끌어올려야 합니다. 핵심은:

1. 숫자가 가장 잘 읽히는 타이포그래피
2. 의미를 전달하는 색상 체계
3. 1px이라도 더 데이터에 쓰는 레이아웃 밀도
4. 전환 마찰이 0에 가까운 네비게이션

이 네 가지가 "차원이 다른 UX"와 "또 하나의 데이터 대시보드"를 가르는 차이입니다.
