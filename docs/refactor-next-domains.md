# 피드 이후 리팩토링 범위

기준은 Mac mini의 읽기 전용 리허설 사본이다. 최신 MacBook 자료나 운영 전환 완료를 뜻하지 않는다. 현재 PostgreSQL fixture는 주 DB의 일반 테이블 175개 중 피드 관련 20개를 보존한다. 나머지 일반 테이블 155개와 SQLite의 가상 테이블 5개·내부 shadow 테이블 9개는 이 실험의 보존 범위가 아니다. 별도 DB·파일은 이 숫자에 포함하지 않는다.

| 기능 | 현행 경로·의존성 | PostgreSQL 실험의 상태 |
| --- | --- | --- |
| 국내 산업·섹터 | `/api/spine/industry/map`, `/{sector}`, `/{sector}/peers`; sector/기업·시세·내러티브·문서·수출입·대만/미국 자료와 Peer 게시 파일 | 피드용 자료 일부만 보존. 지도·상세·Peer 미구현 |
| 미국 섹터 | `/api/spine/industry/us/map`, `/us/{ticker}`; 벤치마크·미국 시세·컨콜·기업 연결 | 컨콜 팔로우 등 일부만 보존. 지도·상세 미구현 |
| 검색 | `/api/spine/search`와 문서 검색/FTS; 기업·별칭·그룹·프로젝트와 별도 FTS/벡터 인덱스 | 원문 일부는 보존하지만 검색 및 인덱스 재생성 미구현 |
| 회원·포트폴리오 | `/api/portfolio`와 거래·원칙·상태 쓰기 | 소유권 원장·인증·쓰기 및 회원별 격리 미구현 |
| 수집·쓰기 | 기존 수집/스케줄러와 문서·첨부·여러 DB의 쓰기 | 읽기 실험만 존재. 증분 반영·단일 writer 인계 미구현 |

리허설 사본에는 `stock_prices` 1,224,355행, `us_prices` 144,722행, `sector_map` 193행, `sector_index` 13,302행, `sector_peer_map` 13행, `transcripts` 645행이 있다. `sector_overviews`는 0행이다. 이 행수는 파일의 모든 시점이나 데이터 정확성 검증이 아니다.

현재 읽기 전용 viewer 및 공개 도메인의 섹터 지도는 국내 18개·미국 24개를 반환했다. 국내 한 섹터의 상세와 Peer 경로도 HTTP 200이었고 Peer 그룹 27개를 반환했다. 이는 한 시점의 대표 확인이며 전체 섹터·최신 수집·모든 데이터 일치나 재부팅 복구를 뜻하지 않는다.

다음 수직 단위 후보는 사용자가 실제 누락을 지적한 국내 섹터 지도→섹터 상세→Peer다. 기존 `sector_rs.compute_sector_map()`은 자체 DB 연결을 열고 `peers.read_runtime()`은 별도 `logs/peer-monitor/current.json` 또는 코드의 seed 파일을 읽는다. DB 테이블만 복사하거나 API 응답만 캐시해서 완전 이전으로 간주하지 않는다. 동시점 자료 취득과 Peer 게시 파일·시세 원천, 데이터 행수/대표 기존 화면, 읽기 경계·메모리/저장공간을 확인해야 한다. 사용자 기록을 포함할 수 있는 필드와 공개 권한은 기존 결정에 따라 명시적으로 검토하고, 새 UI나 LLM 호출은 추가하지 않는다.
